You will generate a prompt for an LLM to implement the Mandelbrot set
problem from the Computer Language Benchmarks Game in Java code.

Problem description:
* Plot the Mandelbrot set [-1.5-i, 0.5+i] on an N-by-N bitmap.
* Write output byte-by-byte in portable bitmap format (PBM P4).
* The output must be identical to the reference when validated with:
  cmp output.pbm reference.pbm for N=200.

The following parameters must be used exactly as given:
- Maximum iterations: 50
- Escape threshold: 4.0
- Plot region: real in [-1.5, 0.5], imaginary in [-1.0, 1.0]
- Output: PBM P4 format, bits packed MSB first, zero-padded per row

You will generate a prompt using the Few-Shot Prompting technique.
Definition: few-shot prompts provide the model with one or more examples
of similar solved problems before presenting the target problem. The
examples demonstrate the expected style and structure of the response
without specifying the content of the solution. The generated prompt
must orient the model to extract from the example only the general
structure (argument reading, main loop, output to stdout).

The generated prompt must ensure that the Java code that the target
LLM will produce:
- Is implemented in Java
- Receives N as a command-line argument via Integer.parseInt(args[0])
- Uses exactly 50 iterations and escape threshold 4.0
- Writes PBM P4 header and binary pixel data to stdout
