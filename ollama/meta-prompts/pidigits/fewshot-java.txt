You will generate a prompt for an LLM to implement the pidigits problem
from the Computer Language Benchmarks Game in Java code.

Problem description:
- Calculate the first N digits of Pi using arbitrary precision arithmetic
- Print digits 10 per line with the running total of digits calculated
- The output must be identical to the reference when validated with:
  diff output.txt reference.txt for N=30.

Algorithm requirements:
Use the Unbounded Spigot Algorithm (Gibbons) with the following
step-by-step operations using arbitrary precision arithmetic:

Initial state:
- q = 1, r = 0, t = 1, k = 0

next_step (advance the algorithm by one term):
- k = k + 1
- r = r + 2*q
- r = r * (2*k + 1)
- t = t * (2*k + 1)
- q = q * k

extract(x):
- return floor((q*x + r) / t)

produce(d):
- q = q * 10
- r = (r - t*d) * 10

Digit selection:
- Call next_step until q > r is false
- Compute d = extract(3)
- If d == extract(4), output digit d and call produce(d)
- Otherwise call next_step again

Output format:
- 10 digits per line
- If the last line has fewer than 10 digits, pad with spaces on the right
- Each line ends with tab, colon, and running total: "\t:N"
- N received via command-line argument

You will generate a prompt using the Few-Shot Prompting technique.
Definition: few-shot prompts provide the model with one or more examples
of similar solved problems before presenting the target problem. The
examples demonstrate the expected style and structure of the response
without specifying the content of the solution. The generated prompt
must orient the model to extract from the example only the general
structure (argument reading, stateful loop, formatted output to stdout).
