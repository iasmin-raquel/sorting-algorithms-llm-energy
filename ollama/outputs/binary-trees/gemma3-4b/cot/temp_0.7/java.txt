The goal is to produce output identical to the reference when validated using `diff output.txt reference.txt`.

Here's a breakdown of the task and the expected code structure:

**1. Problem Understanding:**
The core requirement is to create perfect binary trees (at minimum the number of allocations of Jeremy Zerfas's C program) before deallocation, without any optimizations. This means allocating nodes for the entire tree structure upfront, even if not all levels are immediately used. Leaf nodes must have identical memory allocation as interior nodes.

**2. Code Structure and Functionality:**

   - **Parameters:**

     - `max_depth = max(min_depth + 2, N)` (Calculate this based on `N`)

   - **Long-Lived Tree:** Allocate and maintain a long-lived binary tree that survives all other allocations and deallocations. This tree should remain consistently accessible throughout the program's execution.
   - **Bottom-Up Trees:** Create multiple binary trees, starting from smaller depths and increasing them in steps of 2, up to `max_depth`.  For each depth 'D', allocate a tree, walk it counting nodes, deallocate the tree, and repeat `iterations` times.
   - **Node Counting & Deallocation:** Implement logic to count nodes within each allocated tree during traversal. Ensure proper deallocation of each tree after use.
   - **Output Formatting:** Generate output in the specified format:  "depth\t trees of depth D\t check: C".

**3. Step-by-Step Reasoning & Code Generation:**

*   **Initialization:** Start by setting `N` from the command line arguments. Calculate `min_depth`, `max_depth`, and `stretch_depth`.
*   **Looping:** Iterate through depths from `min_depth` to `max_depth` with a step of 2. For each depth, calculate the number of iterations per tree based on the formula: `iterations = 1 << (max_depth - depth + min_depth)`.
*   **Tree Allocation & Deallocation:** Inside the loop:
    *   Allocate a binary tree of the current depth.
    *   Traverse the tree, counting the nodes.
    *   Deallocate the tree.
*   **Long-Lived Tree Maintenance:** Ensure the long-lived tree is always accessible and remains valid after allocations and deallocations.
*   **Output Generation:**  Generate the output string for each depth using the calculated values and the specified format.

Now, implement the complete Java program following these guidelines.  The code must be executable and produce the exact expected output when run with a specific `N` value.
