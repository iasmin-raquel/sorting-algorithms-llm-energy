**Target Problem:**
Implement a Java program that:
1. Receives `N` as a command-line argument.

### **Key Requirements**
- **Language**: Pure Java (no external libraries).
- **Input Handling**:
  - Parse `N` from `args[0]`.
  - Use `min_depth = 4`, compute `max_depth` and `stretch_depth` as per formula.
- **Tree Logic**:
  - Allocate/deallocate trees in the specified order (stretch → bottom-up → long-lived).
  - Ensure leaf nodes match interior nodes in memory allocation.
- **Output Format**:
  - Exactly match the template for each tree type (e.g., `"I\t trees of depth D\t check: C"`).
  - Use `\t` as a tab character, not spaces.
- **No Optimizations**: Do not skip allocations or deallocations.
- **Validation**: Assume `diff output.txt reference.txt` will validate correctness for `N=10`.
