### Prompt Structure
Create a Python script that implements the Binary Trees problem from the Computer Language Benchmarks Game. The script should define a binary tree node structure with left and right child pointers, allocate and deallocate binary trees, and produce output in the specified format.

### Key Requirements
- The script must be implemented in Python
- It should accept N as a command-line argument
- min_depth, max_depth, and stretch_depth should be defined as per the problem description
- The script should define a tree node structure with left and right child pointers
- It should implement the stretch tree, long-lived tree, and bottom-up tree logic as described
- The output format should match the one specified in the problem description

### Variable Values
- min_depth: 4
- max_depth: computed as max(min_depth + 2, N)
- stretch_depth: max_depth + 1
- iterations: 1 << (max_depth - depth + min_depth)
- N: received via command-line argument

### Notes
Ensure that the output is identical to the reference when validated with "diff output.txt reference.txt" for N=10. The script should not optimize away the work, and leaf nodes must be the same as interior nodes, with the same memory allocation.
