```text

Now, generate the C++ code. The code should:

1.  Read the value of 'N' from the command-line argument.
2.  Implement the repeat fasta algorithm using the ALU sequence as provided.
3.  Implement the weighted random selection fasta algorithm using the IUB alphabet and probabilities, generating a sequence of length 3\*N.
4.  Implement the Homo sapiens frequency fasta algorithm using the Homo sapiens alphabet and probabilities, generating a sequence of length 5\*N.
5.  Use the following LCG constants: IM = 139968, IA = 3877, IC = 29573, Seed = 42.  Do not cache the random number sequence.
6.  Output the three sequences in the specified format (line length 60 characters, with the appropriate headers).
```

### Key Requirements
*   C++ code must be generated.
*   The program must accept 'N' as a command-line argument.
*   Use the LCG constants exactly as defined above.
*   Utilize the provided ALU, IUB, and Homo sapiens alphabet probabilities.
*   Output must adhere to the specified format (3 sequences, line length 60).
*   No random number caching should be employed.
*   The code must produce identical output when validated with `diff output.txt reference.txt for N=1000`.
