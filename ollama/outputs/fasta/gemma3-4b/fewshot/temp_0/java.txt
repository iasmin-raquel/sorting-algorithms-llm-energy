1.  Repeat Fasta of the ALU sequence with N characters.
2.  Random Fasta using the IUB alphabet with N characters.
3.  Random Homo sapiens frequency with N characters.

The output should be formatted as follows:

```
>SEQUENCE_TYPE

```

Where `SEQUENCE_TYPE` is one of ">ONE Homo sapiens alu", ">TWO IUB ambiguity codes", or ">THREE Homo sapiens frequency". The `[Sequence Data]` part contains the generated DNA sequence.  Ensure that the output matches exactly what's expected when validated with `diff output.txt reference.txt for N=1000`.

*   It must accept an integer 'N' as a command-line argument.

*   Use the provided ALU, IUB, and Homo sapiens alphabets with their exact probabilities.
*   The output must be formatted exactly as specified above (sequence type followed by the DNA sequence).
*   The generated sequences should match the reference when validated using `diff`.
*   Do not use any external libraries beyond standard Java libraries.
