### Prompt Structure

**Chain-of-Thought Reasoning for Fasta Sequence Generation in Java:**

1. **Problem Decomposition:**
   - The task is divided into three main parts: generating a repeated fasta sequence from an ALU template, and two random fasta sequences based on weighted probabilities for IUB ambiguity codes and Homo sapiens nucleotides.
   - For each part, the following steps must be followed:
     - Parse command-line argument `N` to determine output length.
     - Define cumulative probability distributions for each alphabet (IUB and Homo sapiens).
     - Use a Linear Congruential Generator (LCG) with given constants (`IM`, `IA`, `IC`, Seed=42) to generate random numbers.
     - For each nucleotide, select it by comparing the generated random number against its cumulative probability range.

2. **Implementation Steps:**
   - **Repeat Fasta:** Copy the ALU sequence in chunks of 2 characters (to match `n*2` output length), ensuring no padding or truncation.
   - **Random Fasta for IUB Alphabet:**
     - Convert given probabilities to cumulative probabilities.
     - Use LCG to generate random numbers, then select nucleotides based on these ranges.
   - **Random Fasta for Homo sapiens Alphabet:**
     - Repeat the same process with adjusted probabilities (a=0.3029549..., etc.).
   - **Output Formatting:** Ensure each sequence is exactly 60 characters long per line and formatted as specified (`>ONE`, `>TWO`, `>THREE`).

3. **LCG Implementation:**
   - The LCG must be applied sequentially for each nucleotide selection, without caching results.
   - Seed initialization must start at 42, and the formula `(Seed * IA + IC) % IM` must be used to update the seed.

4. **Edge Cases & Validation:**
   - Handle cases where `N` is not divisible by 2 (for repeat fasta), but ensure output length matches `n*2`, `n*3`, or `n*5` for each sequence.
   - Validate output against reference files using `diff` to confirm correctness.

  - Use exact constants: `IM=139968`, `IA=3877`, `IC=29573`, Seed=42.

- **Output Format:**
  - Exactly three sequences per run, with line lengths of 60 characters.
  - Prefixes must match exactly (`>ONE`, `>TWO`, `>THREE`).
  - Lengths must be `n*2`, `n*3`, and `n*5` for the respective sequences.
