### Key Requirements
- **C++ Implementation**: Must use C++ syntax and standard libraries.
- **Command-line Argument Parsing**: Read `N` from `argv[1]` (e.g., `./program 5`).
- **LCG Usage**: Implement the provided LCG (`IM=139968`, `IA=3877`, `IC=29573`) with seed=42, no caching.
- **Output Format**:
  - Line length: Exactly 60 characters per line (pad/truncate as needed).
  - Three sequences in order:
    1. Repeat ALU sequence (`>ONE Homo sapiens alu` + `n*2` chars).
    2. Random IUB sequence (`>TWO IUB ambiguity codes` + `n*3` chars).
    3. Random Homo sapiens sequence (`>THREE Homo sapiens frequency` + `n*5` chars).
- **Weighted Random Selection**: Use cumulative probabilities for each alphabet.
- **No Caching**: Generate random numbers on-demand per nucleotide.

### Notes
- **Output Truncation**: If `N*length` exceeds line limits (e.g., `n*2=1000`), split into multiple lines of 60 chars each.
- **Edge Cases**: Handle invalid `N` (e.g., non-integer input) gracefully or exit with an error message.
- **Cumulative Probabilities**: For weighted random selection, compute cumulative probabilities for each alphabet and use binary search to match random numbers efficiently. The prompt expects a linear search as per the problem description.
- **Random Seed**: Always initialize `seed=42` in `main()` before generating sequences.
