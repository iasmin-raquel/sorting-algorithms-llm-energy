### Prompt Structure
Write a C++ program that takes the number of sequences to generate (N) as a command-line argument. The program should output three DNA sequences in order:

1. A sequence generated by repeating the ALU sequence, followed by n*2 characters
2. A sequence generated by weighted random selection from the IUB alphabet with specified probabilities, followed by n*3 characters
3. A sequence generated by weighted random selection from the Homo sapiens alphabet with specified probabilities, followed by n*5 characters

The output should be formatted as specified in the problem description.

### Key Requirements
- Implemented in C++
- Receives N as a command-line argument
- Uses the LCG with the following constants: IM = 139968, IA = 3877, IC = 29573, Seed = 42
- Uses the ALU sequence, IUB and Homo sapiens alphabets with their exact probabilities as defined in the problem description
- Produces output in the exact format specified in the problem description
- Does not cache the random number sequence

### Notes
The model should decompose the problem into intermediate steps, such as:
- Converting the expected probability of each nucleotide into cumulative probabilities
- Matching a random number against those cumulative probabilities to select each nucleotide using linear search
- Generating DNA sequences by repeating the ALU sequence, selecting from the IUB alphabet and Homo sapiens alphabets with specified probabilities
- Formatting the output according to the problem description.
