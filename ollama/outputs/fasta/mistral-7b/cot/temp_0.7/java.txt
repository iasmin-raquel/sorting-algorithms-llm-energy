### Key Requirements
- The program must be implemented in Java
- It should accept N as a command-line argument
- The LCG constants IM, IA, IC, and Seed must be used exactly as given
- Use the ALU sequence, IUB alphabet with their exact probabilities, and Homo sapiens alphabet with their exact probabilities provided
- Generate output in the specified format with line length of 60 characters
- Do not cache the random number sequence
