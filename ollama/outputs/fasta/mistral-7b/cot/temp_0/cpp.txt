### Prompt Structure
Write a C++ program that takes the number of sequences to generate (N) as a command-line argument. The program should generate three DNA sequences in order:

1. A repeat fasta sequence of the provided ALU sequence with n*2 characters. The sequence should be prefixed with ">ONE Homo sapiens alu".
2. A random fasta sequence using the IUB ambiguity codes with n*3 characters. The sequence should be prefixed with ">TWO IUB ambiguity codes".
3. A random fasta sequence using the Homo sapiens frequency with n*5 characters. The sequence should be prefixed with ">THREE Homo sapiens frequency".

The output should adhere to the specified format, and the program should use the provided LCG for generating random numbers.

### Key Requirements
- Implemented in C++
- Receives N as a command-line argument
- Uses the LCG with the exact constants defined above (IM = 139968, IA = 3877, IC = 29573, Seed = 42)
- Utilizes the ALU sequence, IUB and Homo sapiens alphabets with their exact probabilities as defined above
- Produces output in the exact format specified above
- Does not cache the random number sequence
