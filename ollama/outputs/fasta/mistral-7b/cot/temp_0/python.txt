### Prompt Structure
Write a Python script that takes the number of sequences to generate (N) as a command-line argument. The script should implement three functions: `repeat_fasta`, `random_fasta_IUB`, and `random_fasta_Homo`.

The `repeat_fasta` function generates DNA sequences by copying from the given ALU sequence, repeating it n*2 times.

The `random_fasta_IUB` function generates DNA sequences using weighted random selection from the IUB alphabet with the provided probabilities. The output should be n*3 characters long.

The `random_fasta_Homo` function generates DNA sequences using weighted random selection from the Homo sapiens alphabet with the provided probabilities. The output should be n*5 characters long.

The script should produce output in the specified format, with each sequence having a line length of 60 characters.

### Key Requirements
- The script must be implemented in Python
- The script should receive N as a command-line argument
- The script must use the LCG with the exact constants defined for generating random numbers
- The script must use the ALU sequence, IUB and Homo sapiens alphabets with their exact probabilities as defined
- The script should not cache the random number sequence
- The output format should match the one specified in the problem description
