### Prompt Structure
You are tasked with implementing the Fasta problem from the Computer Language Benchmarks Game in Java. The code must generate DNA sequences based on specified alphabets using a naive linear congruential generator (LCG) and produce output in a strict format. The code must handle three distinct scenarios: repeat fasta, random fasta for IUB, and random fasta for Homo sapiens. The output must match the reference when validated with `diff output.txt reference.txt` for N=1000.

### Key Requirements
- Use the exact LCG parameters: IM=139968, IA=3877, IC=29573, Seed=42.
- Use the ALU sequence, IUB alphabet, and Homo sapiens alphabet with their exact probabilities.
- Generate sequences of lengths 2*N, 3*N, and 5*N respectively.
- Output must adhere to the specified format: 60-character line length, three sequences in order.
- Ensure the LCG is not cached, and random numbers are generated on-the-fly.
- The code must receive N as a command-line argument.
