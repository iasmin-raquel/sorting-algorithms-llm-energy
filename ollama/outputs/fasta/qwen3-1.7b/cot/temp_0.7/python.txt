### Prompt Structure
You are to implement the Fasta problem from the Computer Language Benchmarks Game in Python. The task involves generating three types of DNA sequences based on given alphabets and probabilities, using a naive linear congruential generator (LCG) to generate random numbers. The output must match the reference when validated with `diff output.txt reference.txt` for N=1000.

### Key Requirements
- Use the exact LCG constants: IM=139968, IA=3877, IC=29573, Seed=42.
- Generate sequences based on the provided ALU, IUB, and Homo sapiens alphabets with their exact probabilities.
- Ensure the output format has 60-character lines and three sequences in order: 
  1. ">ONE Homo sapiens alu" followed by repeat fasta of ALU with n*2 characters.
  2. ">TWO IUB ambiguity codes" followed by random fasta of IUB with n*3 characters.
  3. ">THREE Homo sapiens frequency" followed by random fasta of Homo sapiens with n*5 characters.
- Do not cache the random number sequence.
- Validate the output with `diff output.txt reference.txt` for N=1000.

- IUB alphabet probabilities: a=0.27, c=0.12, g=0.12, t=0.27, B=0.02, D=0.02, H=0.02, K=0.02, M=0.02, N=0.02, R=0.02, S=0.02, V=0.02, W=0.02
- Homo sapiens alphabet probabilities: a=0.3029549426680, c=0.1979883004921, g=0.1975473066391, t=0.3015094502008

### Notes
- The LCG must be used naively without caching, ensuring each random number is generated on the fly.
- The cumulative probabilities for each nucleotide must be calculated accurately to match the weighted probabilities.
- The output must strictly adhere to the 60-character line length and sequence order, with no trailing spaces or extra lines.
