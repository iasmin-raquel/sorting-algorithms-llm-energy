### Prompt Structure
You are to implement the Computer Language Benchmarks Game Fasta problem in C++. The task involves generating three types of DNA sequences based on given alphabets and probabilities, using a naive linear congruential generator (LCG) with specific constants. The output must match a reference file when validated with `diff output.txt reference.txt` for a given N.

### Key Requirements
- Generate three sequences: repeat fasta, random fasta with weighted selection, and Homo sapiens fasta.
- Use the ALU sequence, IUB alphabet, and Homo sapiens alphabet with exact probabilities.
- Use the LCG with IM=139968, IA=3877, IC=29573, Seed=42.
- Ensure output matches the specified format (60-character lines, three sequences with exact lengths).
- Do not cache the random number sequence.
