### Prompt Structure
You are to implement the Fasta problem from the Computer Language Benchmarks Game in Java. The task involves generating DNA sequences using specific algorithms and parameters. The code must:
- Generate sequences by repeating a given DNA sequence (repeat fasta).
- Generate sequences by weighted random selection from alphabets (random fasta).
- Use a naive linear congruential generator (LCG) with exact constants.
- Output in the specified format with three sequences of different lengths.
- Validate against a reference using `diff output.txt reference.txt` for N=1000.

### Key Requirements
- Use the LCG with IM=139968, IA=3877, IC=29573, Seed=42.
- Generate sequences based on ALU, IUB, and Homo sapiens alphabets with exact probabilities.
- Output three sequences in order: 
  1. ">ONE Homo sapiens alu" followed by repeat fasta of ALU with n*2 characters.
  2. ">TWO IUB ambiguity codes" followed by random fasta of IUB with n*3 characters.
  3. ">THREE Homo sapiens frequency" followed by random fasta of Homo sapiens with n*5 characters.
- Ensure the output format matches the specified line length (60 characters) and sequence lengths.
- Do not cache the random number sequence.
