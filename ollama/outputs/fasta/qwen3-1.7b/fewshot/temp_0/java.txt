### Prompt Structure
Generate Java code that implements the Fasta problem from the Computer Language Benchmarks Game. The code must:
1. Read a command-line argument N to determine the number of sequences to generate.
2. Generate three types of DNA sequences:
   - **Repeat fasta**: Copy the ALU sequence (given) exactly N*2 characters.
   - **Random fasta**: Use weighted random selection from IUB and Homo sapiens alphabets (exact probabilities).
3. Output sequences in the specified format (60-character lines, three sequences with exact lengths).
4. Use the naive LCG with IM=139968, IA=387, IC=29573, Seed=42.
5. Ensure output matches the reference when validated with `diff output.txt reference.txt`.

### Key Requirements
- Use the ALU sequence as provided.
- Apply exact probabilities for IUB and Homo sapiens alphabets.
- Generate sequences of lengths N*2, N*3, N*5.
- Avoid caching the LCG sequence.
- Output in the exact format: ">ONE ...", ">TWO ...", ">THREE ...".
- Ensure cumulative probabilities are calculated correctly for each nucleotide.
