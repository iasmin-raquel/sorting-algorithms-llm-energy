### Prompt Structure

The code must use a naive linear congruential generator (LCG) with the exact constants provided, and produce output in the specified format. The code must handle the ALU sequence, IUB alphabet, and Homo sapiens alphabet with their exact probabilities, and ensure the output matches the reference when validated.

### Key Requirements
- Generate three sequences: repeat fasta, random fasta (IUB), and random fasta (Homo sapiens).
- Use the LCG with IM=139968, IA=3877, IC=29573, Seed=42.
- Use the ALU sequence, IUB alphabet, and Homo sapiens alphabet with their exact probabilities.
- Output must be 60 characters per line, with specific headers and lengths.
- Do not cache the random number sequence.
- Validate output with `diff output.txt reference.txt` for N=1000.
