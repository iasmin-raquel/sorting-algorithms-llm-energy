### Prompt Structure
You are an expert C++ programmer tasked with implementing the Mandelbrot set benchmark problem from the Computer Language Benchmarks Game. Your goal is to generate a complete and executable C++ program that accurately plots the Mandelbrot set and produces a PBM P4 bitmap file suitable for validation.

First, let's break down the problem into manageable steps. We need to:

1.  **Understand the Problem:** The task involves generating an image of the Mandelbrot set within the region [-1.5 - i, 0.5 + i] in the complex plane. This requires calculating whether a given point (represented by its real and imaginary parts 'C') belongs to the set after a fixed number of iterations.

2.  **Define Parameters:** We are given specific parameters:
    *   Maximum Iterations: 50
    *   Escape Threshold (squared): lim = 2.0 * 2.0
    *   Coordinate Mapping: The real and imaginary parts of the complex number 'C' are mapped to the pixel coordinates using the formulas `real(C) = 2.0 * x / N - 1.5` and `imag(C) = 2.0 * y / N - 1.0`, where (x, y) is the pixel coordinate and N is the image size.
    *   Iteration Formula:  Z = Z\*Z + C, starting with Z = 0.

3.  **Implement the Algorithm:** The core logic involves iterating through each pixel in the bitmap (represented by x and y coordinates). For each point 'C', we perform the iteration formula up to 50 times. If |Z|² exceeds the escape threshold at any point, we mark that pixel as not belonging to the set. Otherwise, we assume it belongs to the set.

4.  **Output Formatting:** The output must be in PBM P4 format. This means:
    *   The header should be "P4\n" followed by "N N\n", where N is the image size.
    *   Each pixel should be represented using 8 bits, with the most significant bit (MSB) indicating whether the point belongs to the set (1) or not (0).
    *   The last byte of each row should be padded with zeros if N is not divisible by 8.
    *   The binary pixel data and header must be written to standard output.

5.  **Command-Line Argument:** The C++ program should accept the image size 'N' as a command-line argument.

6. **Validation:** The generated code must produce an output that is identical to a reference file when validated using `cmp output.pbm reference.pbm for N=200`.

Now, write the C++ code to fulfill these requirements. Focus on clarity and efficiency.  Include comments to explain key steps.
```cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

int main(int argc, char* argv[]) {
    if (argc != 2) {
        std::cerr << "Usage: mandelbrot N\n";
        return 1;
    }

    int N = std::stoi(argv[1]);

    if (N <= 0) {
        std::cerr << "N must be a positive integer.\n";
        return 1;
    }

    std::cout << "P4\n";
    std::cout << N << " " << N << "\n";

    for (int y = 0; y < N; ++y) {
        for (int x = 0; x < N; ++x) {
            // Coordinate mapping
            double realC = 2.0 * x / N - 1.5;
            double imagC = 2.0 * y / N - 1.0;

            std::complex<double> c(realC, imagC);
            std::complex<double> z(0.0, 0.0);

            int iterations = 0;
            while (iterations < 50 && std::abs(z) <= 2.0 * 2.0) {
                z = z * z + c;
                iterations++;
            }

            // Output pixel data (MSB first)
            if (iterations == 50) {
                std::cout << "0 ";
            } else {
                std::cout << "1 ";
            }
        }
        std::cout << "\n";
    }

    return 0;
}
```
