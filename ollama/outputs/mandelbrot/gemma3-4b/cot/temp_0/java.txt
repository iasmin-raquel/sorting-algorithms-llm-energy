### Prompt Structure
You are an expert Java code generator specializing in computer graphics and algorithmic problems. Your task is to generate a complete Java program that implements the Mandelbrot set visualization according to the Computer Language Benchmarks Game problem description. I will provide you with instructions, and you should respond with only the Java code itself.

First, let's break down the requirements step-by-step:

1.  **Input:** The program must accept an integer `N` as a command-line argument, representing the size of the bitmap (N x N).
2.  **Mandelbrot Calculation:** Implement the Mandelbrot set calculation using the following parameters:
    *   Maximum iterations: 50
    *   Escape threshold (squared): lim = 2.0 * 2.0
    *   Iteration formula: Z = Z\*Z + C, starting from Z = (0, 0)
    *   Coordinate mapping: real(C) = 2.0 \* x / N - 1.5; imag(C) = 2.0 \* y / N - 1.0
    *   Use squared magnitude (zr\*zr + zi\*zi) to avoid computing square roots.
3.  **Bitmap Generation:** Generate a bitmap of size N x N, where each pixel represents whether the corresponding point in the complex plane belongs to the Mandelbrot set or not. A point belongs to the set if |Z|² <= lim after all iterations.
4.  **Output Format (PBM P4):** The output must be in the Portable Bitmap (PBM) format with a pixel depth of 4 (P4). This means:
    *   Header: "P4\n" followed by "N N\n"
    *   Pixels packed 8 per byte, MSB first (bit 1 = in set, bit 0 = not in set)
    *   If N is not divisible by 8, the last byte of each row must be padded with zeros on the right.
    *   Write only the header and binary pixel data to standard output (stdout).
5.  **Validation:** The generated bitmap should be identical to a reference bitmap when validated using `cmp output.pbm reference.pbm for N=200`.

Now, write the complete Java code that implements this functionality. Ensure your code is well-structured and efficient.

### Key Requirements
*   The code must be written in Java.
*   It must accept an integer `N` as a command-line argument.
*   It must use exactly 50 iterations for the Mandelbrot calculation.
*   It must use the escape threshold lim = 2.0 * 2.0.
*   The output format must strictly adhere to PBM P4 specifications, including header and binary pixel data.
*   The code should produce a bitmap that is validatable against a reference bitmap using `cmp`.

### Variable Values
*   Maximum iterations: 50
*   Escape threshold (squared): lim = 2.0 * 2.0
*   Coordinate mapping: real(C) = 2.0 * x / N - 1.5; imag(C) = 2.0 * y / N - 1.0
