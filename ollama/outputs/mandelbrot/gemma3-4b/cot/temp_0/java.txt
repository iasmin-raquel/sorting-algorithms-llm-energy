### Prompt Structure
Okay, let's generate a Chain-of-Thought prompt for an LLM to implement the Mandelbrot set in Java according to the Computer Language Benchmarks Game problem.

"You are an expert Java programmer tasked with implementing the Mandelbrot set visualization as specified by the benchmark. Your response should be a complete Java program that fulfills all requirements. First, let's break down the task into logical steps:

1.  **Understand the Problem:** The goal is to generate a bitmap image of the Mandelbrot set within the region [-1.5-i, 0.5+i] for the real and imaginary parts, using a maximum of 50 iterations and an escape threshold of 4.0. The output must be in PBM P4 format (Portable Bitmap - Pixel 4), meaning byte-by-byte binary data with MSB packing and zero padding per row.

2.  **Input Handling:** The program needs to accept the size of the bitmap (N) as a command-line argument. Parse this argument using `Integer.parseInt(args[0])` to determine the dimensions of the output image.

3.  **Mandelbrot Calculation:** Implement the Mandelbrot iteration formula: z_{n+1} = z_n^2 + c, where z and c are complex numbers. The initial value of z should be 0.

4.  **Iteration Loop:** Iterate up to a maximum of 50 times for each pixel. If the magnitude of z exceeds the escape threshold (4.0), mark the point as "escaped" (e.g., set the pixel color to black). Otherwise, continue iterating.

5.  **Bitmap Output:** After all iterations, write the bitmap data to standard output in PBM P4 format. This involves:
    *   Writing the header line: `P4\nNnn\n` (where N is the size of the image and nn is the number of pixels per row).
    *   Writing each pixel's color value (0 or 255) as a single byte, packed MSB first, with zero padding.

6.  **Testing:** The generated code should be tested against the reference output provided in `reference.pbm` for N=200 to ensure correctness.

Now, write the complete Java program following these steps. Include comments to explain your code and make it easy to understand."

### Key Requirements
*   The solution must be implemented in Java.
*   The program must accept the bitmap size (N) as a command-line argument.
*   It must use exactly 50 iterations for the Mandelbrot calculation.
*   The escape threshold must be set to 4.0.
*   The output format must be PBM P4 (Portable Bitmap - Pixel 4), with MSB packing and zero padding per row.
*   The output should be written byte-by-byte to standard output.
*   The program must produce identical output to the reference image when validated for N=200.

### Variable Values
*   Maximum iterations: 50
*   Escape threshold: 4.0
*   Plot region: real in [-1.5, 0.5], imaginary in [-1.0, 1.0]
*   Output format: PBM P4 (bits packed MSB first, zero-padded per row)
