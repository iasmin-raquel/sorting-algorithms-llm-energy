### Prompt Structure
You are an expert Python programmer tasked with implementing the Mandelbrot set benchmark problem. Your goal is to generate a complete Python script that produces a PBM P4 image representing the Mandelbrot set, suitable for validation using the `cmp` command. Follow these steps carefully:

1.  **Understand the Problem:** The task involves generating an image of the Mandelbrot set within the specified region [-1.5-i, 0.5+i] and outputting it in a portable bitmap format (PBM P4). This requires calculating whether each point belongs to the set based on the given iteration parameters.

2.  **Input:** The script must accept an integer `N` as a command-line argument, which determines the size of the image (N x N pixels).

3.  **Iteration Parameters:** Use the following fixed values:
    *   Maximum iterations: 50
    *   Escape threshold (squared): lim = 2.0 * 2.0
    *   Initial value: Z = (0, 0)

4.  **Coordinate Mapping:** Implement the coordinate mapping correctly to transform the complex plane coordinates (x, y) into complex numbers C:
    *   real(C) = 2.0 * x / N - 1.5
    *   imag(C) = 2.0 * y / N - 1.0

5.  **Mandelbrot Set Calculation:** For each point (x, y), iterate the formula Z = Z\*Z + C up to a maximum of 50 iterations. Check if |Z|² <= lim after each iteration. If it exceeds the threshold, the point is not in the set; otherwise, it remains in the set.

6.  **Output Format (PBM P4):**
    *   Header: "P4\n" followed by "N N\n" where N is the image size.
    *   Pixel Data: Pack 8 bits per pixel to represent whether each point belongs to the set or not (1 for in set, 0 for not in set). Use bit 1 as MSB. Pad with zeros on the right if N is not divisible by 8. Write this binary data to standard output.

7.  **Validation:** The generated image should be identical to the reference image when validated using `cmp output.pbm reference.pbm` for N=200. Ensure your code produces the correct binary representation of the Mandelbrot set.

Now, write the complete Python script that implements these steps. Include comments to explain the key parts of the code.

*   The generated output must be valid and produce an image that passes validation with `cmp output.pbm reference.pbm` for N=200.
*   The code should be well-commented and easy to understand.
