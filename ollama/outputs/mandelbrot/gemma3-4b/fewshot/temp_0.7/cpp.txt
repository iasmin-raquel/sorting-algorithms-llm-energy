### Key Requirements
*   The generated code must be valid C++.
*   It should take an integer `N` as a command-line argument.
*   It must use exactly 50 iterations for the Mandelbrot set calculation.
*   The escape threshold must be set to 4.0.
*   The plotting region should cover real values from -1.5 to 0.5 and imaginary values from -1.0 to 1.0.
*   It must output the resulting bitmap in PBM P4 format (byte-by-byte, MSB first, zero-padded per row).
*   The code should include a header for `stdio.h` and `stdlib.h`.

### Variable Values
*   Maximum iterations: 50
*   Escape threshold: 4.0
*   Plot region: real [-1.5, 0.5], imaginary [-1.0, 1.0]
*   Output format: PBM P4 (MSB first, zero-padded)
