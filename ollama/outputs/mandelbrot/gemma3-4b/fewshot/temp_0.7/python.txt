### Prompt Structure
```
You are an expert Python code generator specializing in computer science problems. Your task is to generate a complete Python program that implements the Mandelbrot set visualization using the PBM P4 bitmap format. The code must adhere strictly to the specifications provided, including iteration limits, escape threshold, coordinate mapping, and output formatting.

Here are three examples demonstrating the expected input/output structure and code style:

**Example 1:**
Input: N = 200
Output: (A PBM P4 bitmap file named 'mandelbrot.pbm' containing the Mandelbrot set for N=200, written byte-by-byte to stdout)

**Example 2:**
Input: N = 100
Output: (A PBM P4 bitmap file named 'mandelbrot.pbm' containing the Mandelbrot set for N=100, written byte-by-byte to stdout)

**Example 3:**
Input: N = 50
Output: (A PBM P4 bitmap file named 'mandelbrot.pbm' containing the Mandelbrot set for N=50, written byte-by-byte to stdout)

Now, generate the Python code to visualize the Mandelbrot set based on the following parameters:

Maximum iterations: 50
Escape threshold (squared): lim = 2.0 * 2.0
Coordinate mapping: real(C) = 2.0 * x / N - 1.5; imag(C) = 2.0 * y / N - 1.0
Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
Use squared magnitude (zr*zr + zi*zi) to avoid computing square roots
Output format (PBM P4): Header "P4\n" followed by "N N\n", then pixel data packed 8 per byte, MSB first. If N is not divisible by 8, pad with zeros on the right. Write only the header and binary pixel data to stdout.
Receive N as a command-line argument.

```

### Key Requirements
*   The generated code must be executable Python script.
*   It should receive an integer `N` as a command-line argument.
*   It must accurately implement the Mandelbrot set calculation with 50 iterations and lim = 2.0 * 2.0.
*   The output should conform to the PBM P4 bitmap format (header "P4\n" + "N N\n" + byte-by-byte pixel data).
*   Pixel data should be packed 8 bits per byte, MSB first.  Padding with zeros on the right if `N` is not divisible by 8.
*   The code must write only the header and binary pixel data to stdout.
*   The generated output must be valid when compared using `cmp` against a reference image for N=200, as specified in the problem description.

### Variable Values
*   Maximum iterations: 50
*   Escape threshold (squared): lim = 2.0 * 2.0
*   N: Command-line argument (integer)
*   Real part of C: `2.0 * x / N - 1.5`
*   Imaginary part of C: `2.0 * y / N - 1.0`
*   Iteration formula:  Z = Z\*Z + C
*   Initial value for Z: (0, 0)
*   Magnitude calculation: `zr*zr + zi*zi`

### Notes
*   The prompt emphasizes the "few-shot" approach to guide the model's response. The examples are crucial for setting the expected code structure and style.  Error handling is not explicitly requested, but robust code that handles invalid input or potential issues gracefully would be a strong positive. The LLM should focus on implementing the core Mandelbrot set algorithm and bitmap output correctly.
