### Key Requirements
*   The generated code must be valid C++ code.
*   The code must receive the value of `N` as a command-line argument (argv[1]).
*   The code must use exactly 50 iterations.
*   The escape threshold (`lim`) must be set to 2.0 * 2.0.
*   The output format must be PBM P4, including the header "P4\n" followed by "N N\n".
*   The pixel data must be packed 8 bits per byte (MSB first), with bit 1 indicating set and bit 0 indicating not set.
*   If `N` is not divisible by 8, the last byte of each row must be padded with zeros on the right.
*   The code must write only the header and binary pixel data to stdout.
*   The output should be validatable using `cmp output.pbm reference.pbm for N=200`.

### Variable Values
*   `N`: Integer, determined by the command-line argument (argv[1]).
*   `lim`: 2.0 * 2.0 = 4.0
*   `max_iterations`: 50
*   Output format: PBM P4

### Notes
The prompt emphasizes a few-shot approach to guide the LLM towards generating the correct C++ code structure and adhering to the specified constraints. The examples provided illustrate the expected input/output format and the use of command-line arguments, which should help the model understand the task requirements effectively.  The explicit mention of "byte-by-byte" output is crucial for ensuring the correct PBM P4 formatting.
