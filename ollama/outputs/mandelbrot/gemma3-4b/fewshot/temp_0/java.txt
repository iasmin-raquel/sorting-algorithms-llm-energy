Now, implement a Java program that generates the Mandelbrot set using the following parameters: maximum iterations = 50, escape threshold lim = 2.0 * 2.0. The input `N` represents the size of the bitmap (N x N).  The output should be in PBM P4 format written to stdout, including the header "P4\n" followed by "N N\n", and then the binary pixel data where each byte contains 8 bits representing whether a point is in the set (1) or not (0). Pad the last byte of each row with zeros if `N` is not divisible by 8.  Validate your output using `cmp output.pbm reference.pbm for N=200`.
### Key Requirements
*   The generated code must be written in Java.
*   The program should accept an integer `N` as a command-line argument, representing the bitmap size.
*   It must use exactly 50 iterations and a lim of 2.0 * 2.0.
*   The output format must strictly adhere to PBM P4 (header + binary pixel data).
*   The program should write the header "P4\n" followed by "N N\n" to stdout.
*   The binary pixel data should be packed 8 bits per byte, with MSB first (bit 1 = in set, bit 0 = not in set).
*   Padding with zeros on the right of each row is required if `N` is not divisible by 8.
*   The output must be valid for comparison using `cmp output.pbm reference.pbm` when N=200.

### Variable Values
*   Maximum iterations: 50
*   Escape threshold (squared): lim = 2.0 * 2.0
*   N: Integer input from command line, representing the bitmap size.
*   Iteration formula: Z = Z\*Z + C, starting from Z = (0, 0)
*   Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
### Notes

The "PBM P4" format is crucial, and the padding requirement adds complexity that needs careful handling during the pixel data generation.
