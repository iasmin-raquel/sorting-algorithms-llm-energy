Now, implement the Mandelbrot set problem as described below:

Plot the Mandelbrot set [-1.5-i, 0.5+i] on an N-by-N bitmap. Write output byte-by-byte in portable bitmap format (PBM P4). The output must be identical to the reference when validated with: cmp output.pbm reference.pbm for N=200.

Maximum iterations: 50
Escape threshold: 4.0
Plot region: real in [-1.5, 0.5], imaginary in [-1.0, 1.0]
Output: PBM P4 format, bits packed MSB first, zero-padded per row

```

### Key Requirements
*   The code must be written in Python.
*   It should receive the size of the bitmap (N) as a command-line argument via `int(sys.argv[1])`.
*   It must use exactly 50 iterations and an escape threshold of 4.0.
*   It needs to generate PBM P4 header text and binary pixel data to stdout. The output should be byte-by-byte, packed MSB first, with zero padding per row.

### Variable Values
*   `N`: Command-line argument representing the bitmap size (integer).
*   `max_iterations`: 50
*   `escape_threshold`: 4.0
*   `real_min`: -1.5
*   `real_max`: 0.5
*   `imag_min`: -1.0
*   `imag_max`: 1.0

### Notes
*   Focus on the structure and output format of the example code provided.  Do not include any unnecessary comments or explanations in the generated code. The goal is to produce a functional implementation based solely on the examples.
