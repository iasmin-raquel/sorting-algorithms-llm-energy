### **Prompt Structure**
**Task:** Generate a C++ program to compute the Mandelbrot set for an N×N grid over the complex plane `[-1.5 - i, 0.5 + i]` using exactly the following constraints:

#### **Step-by-Step Reasoning:**
1. **Input Handling:**
   - The program should read `N` from the command line (e.g., `./mandelbrot 200`).
   - Validate that `N` is a positive integer and exits gracefully if invalid.

2. **Complex Plane Mapping:**
   - For each pixel `(x, y)` (where `x`, `y ∈ [0, N-1]`), compute the corresponding complex constant `C` using:
     ```
     real(C) = 2.0 * x / N - 1.5
     imag(C) = 2.0 * y / N - 1.0
     ```
   - Round to nearest float for precision (e.g., `real(C) = floor(real(C) + 0.5)`).

3. **Mandelbrot Algorithm:**
   - Initialize `Z` = `(0.0, 0.0)` for all iterations.
   - For each iteration `i ∈ [0, 49]`:
     - Compute `new_Z = Z² + C` using squared magnitude updates (no sqrt):
       ```
       zr_new = zr² - zi² + real(C)
       zi_new = 2 * zr * zi + imag(C)
       ```
     - Check if `|Z|² > lim = 4.0` (escape condition). If so, the point is **not** in the set.
   - After 50 iterations, if `|Z|² ≤ lim`, the point belongs to the set.

4. **Output Format (PBM P4):**
   - **Header:** Write `P4\nN N` to stdout.
   - **Pixels:** For each row:
     a) Pack bits into bytes (MSB = in-set, LSB = not).
     b) If `N % 8 ≠ 0`, pad the last byte with zeros to align rows to 1-byte boundaries.

5. **Edge Cases:**
   - Handle floating-point precision carefully (e.g., `real(C)`/`imag(C)` truncation vs. rounding).
   - Ensure no infinite loops if rounding artifacts cause wrong iteration stops.

### **Notes**
- **Rounding Ambiguity:** The prompt assumes `real_C`/`imag_C` should be **rounded** (e.g., `-1.5 + 0.6 = -0.9`), but must match the reference exactly. Test with N=200 to validate.
- **Bit Packing:**
  - For N=8, each row outputs `N/8` bytes. For odd rows, pad with zeros (e.g., N=11 → 1 byte + 3 zero bits).
- **Floating-Point Safety:** Avoid `-0.0` vs. `+0.0` comparisons; use `fabs(zr) > lim` to detect escape conditions.
- **Expected Behavior:**
  - The LLM should output a deterministic binary pixel stream with no assumptions about external tools (e.g., no `system("cmp")`).
  - For N=200, the output must match the reference *byte-for-byte* when padded correctly.
