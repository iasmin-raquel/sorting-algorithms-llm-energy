### Prompt Structure

You are tasked with generating a Python program to compute and output the Mandelbrot set for an N×N grid within the specified region using the **PBM P4** format. Below is the step-by-step reasoning and implementation plan:

#### Step 1: Define Inputs & Constants
- The program must take `N` as a command-line argument (integer).
- Fixed parameters must be enforced:
  - Maximum iterations = **50**.
  - Escape threshold = **4.0**.
  - Complex plane region: real ∈ [-1.5, 0.5], imaginary ∈ [-1.0, 1.0].

#### Step 2: Mapping to Pixel Coordinates
- For each pixel `(i,j)` in the grid (0-indexed), compute its corresponding point `c = (real_part, imag_part)`:
  ```
  real_part = -1.5 + (0.5 - (-1.5)) * i / (N - 1)
  imag_part = -1.0 + (1.0 - (-1.0)) * j / (N - 1)
  ```

#### Step 3: Mandelbrot Iteration Logic
- For each `c`, iterate `z = c + z²` for up to **50** times.
- If `|z| > 4.0` at any step, the point is **not** in the set; otherwise, it is.

#### Step 4: PBM P4 Format Output
1. Write header:
   ```
   P4\nN\n\n
   ```
2. Pack each pixel as a single bit (MSB first) and zero-pad rows to byte boundaries.
3. Output binary data directly to `stdout` for validation against a reference.

#### Step 5: Code Implementation Notes
- Use `sys.argv[1]` to fetch `N`.
- Avoid floating-point precision errors by rounding intermediate steps to **7 decimal places**.
- Ensure zero-padding in the packed byte stream (e.g., `0b0100` for black, `0b1000` for white).

---
### Key Requirements
- **Input Handling**:
  - Parse `N` from `sys.argv[1]`.
  - Exit if `N` is invalid (<2).
- **Precision Control**:
  - Enforce **7 decimal places** in complex arithmetic to avoid rounding errors.
- **Output Formatting**:
  - Strictly follow PBM P4 binary format (no text, only raw bits).
  - Bytes must be packed MSB-first; zero-padding is mandatory.
- **Mandelbrot Logic**:
  - Use **exact escape threshold** (4.0) and **fixed iterations** (50).

### Notes
- **Precision Ambiguity**: Round intermediate results to 7 decimal places to align with reference outputs. Ambiguous results may differ if not rounded.
- **Edge Cases**:
  - `N=2` or `N=3` will produce trivial outputs (no meaningful Mandelbrot). Validate correctness for `N ≥ 200`.
- **Performance**: For large `N`, optimize packed bit operations to avoid memory bottlenecks.
- **Validation**: The output must match the reference byte-for-byte when compared with a hardcoded reference PBM (e.g., `cmp output.pbm <reference.pbm` for `N=200`).
