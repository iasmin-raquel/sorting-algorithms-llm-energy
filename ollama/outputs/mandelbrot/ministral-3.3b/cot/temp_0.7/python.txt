### Prompt Structure
Act as a Python programmer tasked with implementing the Mandelbrot set plot in PBM (P4) format for a given grid size `N`. You must follow strict specifications to ensure correctness and compatibility with the reference validation test (cmp output.pbm reference.pbm). Below is your task broken into clear reasoning steps:

#### **Problem Decomposition**
1. **Input Handling**:
   - Take `N` as a command-line argument, where `N` determines the grid size (e.g., 200 for validation).
   - Validate that `N` is an integer and divisible by 8 (since PBM requires 8-bit packing per row).

2. **Coordinate Mapping**:
   - For each pixel at `(x, y)` in the grid:
     - Map real part of `C` (complex number) to:
       `real(C) = 2.0 * x / N - 1.5`
     - Map imaginary part of `C` to:
       `imag(C) = 2.0 * y / N - 1.0`.
   - Ensure floating-point precision and avoid integer truncation.

3. **Mandelbrot Set Iteration**:
   - Initialize `Z = (0, 0)` for each pixel.
   - For `C = real(C) + imag(C)*i`, compute iterations of:
     `Z = Z * Z + C` (using squared magnitude for escape detection).
   - Stop if `|Z|² > lim` (where `lim = 2.0 * 2.0`), otherwise after **50 iterations**.

4. **Output Formatting**:
   - **Header**: Write `"P4\nN N"` to stdout (e.g., `P4\n200 200` for `N=200`).
   - **Pixel Packing**:
     For each row, pack 8 pixels into a single byte, with the **most significant bit (MSB)** representing membership in the set (`1` = set, `0` = not).
     Pad the last byte of incomplete rows with zeros if `N % 8 != 0`.

5. **Edge Cases**:
   - Handle invalid `N` (e.g., non-integer, negative) gracefully.
   - Ensure no floating-point artifacts affect bitwise packing.

6. **Validation**:
   - Your output must match the reference exactly for `N=200`, including byte-by-byte precision.

#### **Algorithm Pseudocode**
```python
def mandelbrot_maps(x, y):
    real = 2 * x / N - 1.5
    imag = 2 * y / N - 1.0
    return complex(real, imag)

def mandelbrot_iterate(C, max_iters=50):
    Z = complex(0, 0)
    lim = 4.0  # since lim = 2^2
    for _ in range(max_iters):
        if (Z.real**2 + Z.imag**2) > lim:
            return False  # Escaped; point is not in set
        Z = Z * Z + C
    return True  # Did not escape; point is in set

def pack_row(pixels, N):
    packed_byte = 0
    for i in range(N // 8):
        byte = pixels[i*8 : (i+1)*8]
        for j, bit in enumerate(byte):
            if bit:  # Set pixel (MSB)
                packed_byte |= (1 << (7 - j))  # MSB first
    # Pad remaining bits with zeros (if N % 8 != 0)
    return packed_byte.to_bytes(1, 'big')

# Full implementation below:
def generate_pbm(N):
    header = f"P4\n{N} {N}\n"
    print(header.encode())

    for y in range(N):  # Rows
        row_bits = []
        for x in range(N):  # Columns
            C = mandelbrot_maps(x, y)
            if mandelbrot_iterate(C):
                row_bits.append(1)  # MSB = set
            else:
                row_bits.append(0)
        packed_row = pack_row(row_bits, N)
        print(packed_row)
```
