### Prompt Structure
**Think step-by-step about how to implement the Mandelbrot set in C++ for a given N (command-line argument), adhering strictly to the CLBG rules. Break down the problem into logical phases:**

1. **Input Handling:**
   - Parse command-line argument `N` and validate it is an integer ≥ 200.
   - If invalid, exit with error code 1.

2. **Coordinate Mapping:**
   - Define a function that maps pixel coordinates `(x, y)` (0-based) to complex plane values `C = C_real + i*C_imag`.
     Use the exact formulas:
     ```
     real(C) = 2.0 * x / N - 1.5
     imag(C) = 2.0 * y / N - 1.0
     ```

3. **Mandelbrot Iteration Logic:**
   - For each pixel `(x, y)`, initialize `Z = (0 + 0i)`.
   - Apply the iteration formula `Z = Z*Z + C` for exactly 50 steps.
   - Track squared magnitude `|Z|² = zr*zr + zi*zi`.
   - If `|Z|² > lim = 4.0` after any step, escape and mark pixel as *not in set*.
   - Otherwise, after all iterations, check if `|Z|² ≤ 4.0`. If true, the point is in the set.

4. **Output Generation:**
   - Write PBM P4 header: `"P4\nN N"` (no newline after `N`).
   - Pack pixels row-wise into bytes with MSB-first encoding:
     - Each pixel contributes a bit (1=in set, 0=not in set).
     - Group 8 bits per byte; pad the last byte of each row to 8 bits.
   - Output raw binary data directly to stdout.

5. **Edge Cases:**
   - Handle `N % 8 != 0` by padding bytes with zeros on the right.
   - Ensure no trailing whitespace or extra newlines in output.

6. **Code Structure:**
   - Use a loop over rows (`y`) and columns (`x`), computing each pixel’s membership independently.
   - Avoid global variables; declare all necessary types (e.g., `complex<double>`).
   - Optimize iteration loops for clarity but correctness first.

### Key Requirements
- **Strict adherence to CLBG rules**: No deviations from iteration count (50), threshold (`lim=4.0`), or coordinate mapping.
- **Output format**: Exactly PBM P4 header + binary data; no extra metadata.
- **Bit packing**: MSB-first, 8 bits per byte, padded rows if `N % 8 != 0`.
- **No floating-point inaccuracies**: Use exact arithmetic (e.g., avoid rounding).
- **Command-line interface**: Only accept `N` as input; exit gracefully on invalid input.
