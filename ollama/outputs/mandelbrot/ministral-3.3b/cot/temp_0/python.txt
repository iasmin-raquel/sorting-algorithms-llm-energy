### Prompt Structure
**Think step-by-step about how to generate a Python script that computes the Mandelbrot set for an N×N grid within the specified region and outputs it in PBM P4 format. Break down the problem into these key phases:**

1. **Input Handling:**
   - Parse `sys.argv` to extract `N`, ensuring it is validated as an integer.
   - Define constants: `MAX_ITERATIONS = 50`, `ESCAPE_THRESHOLD = 4.0`.
   - Validate that the input region matches exactly:
     - Real axis: `[-1.5, 0.5]` (inclusive bounds).

2. **Grid Initialization:**
   - Create an N×N grid of complex numbers (`c`) covering the specified region.
   - For each pixel `(i,j)`, compute the corresponding real and imaginary coordinates:
     ```
     real = -1.5 + (0.5 + 1.5) * i / (N - 1)
     imag = -1.0 + (1.0 + 1.0) * j / (N - 1)
     ```

3. **Mandelbrot Iteration Logic:**
   - For each `c`, iterate over `z = 0` and compute:
     ```
     z_new = z² + c
     ```
   - Stop iterating if `|z| > ESCAPE_THRESHOLD` or reach `MAX_ITERATIONS`.
   - Track the iteration count for each pixel.

4. **PBM P4 Output:**
   - Write a header line: `"P4"` (no whitespace).
   - Follow with two integers: `N` (width) and `1` (grayscale, bits per pixel).
   - For each row:
     - Pack 8 pixels into a byte (MSB-first), zero-padded if necessary.
     - Use the iteration count as grayscale value (0–50 → 0–255 scaling).

**Constraints:**
- Do not hardcode any values except those explicitly required by the problem.
- Ensure binary pixel data is written in raw bytes, with no extra whitespace or metadata.
