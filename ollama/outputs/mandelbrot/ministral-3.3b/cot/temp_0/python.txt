### Prompt Structure
Think step-by-step about how to generate a Python script that computes the Mandelbrot set within the specified constraints. The script must:

1. Take an integer `N` (the size of the bitmap) as a command-line argument.
2. Define the coordinate mapping for the complex plane, converting pixel coordinates `(x,y)` into complex numbers `C = real(C) + imag(C)*i`.
3. Implement the Mandelbrot iteration algorithm to determine if each point belongs to the set by checking whether `|Z|²` exceeds the escape threshold after 50 iterations.
4. Pack binary pixel data (1 bit per pixel, MSB first) into bytes for PBM P4 output format, ensuring proper padding with zeros if `N % 8 != 0`.
5. Write the header `"P4\nN N"` followed by packed binary pixel data to stdout.

**Chain-of-thought reasoning:**
- First, derive the exact mapping between pixel coordinates and complex plane values using the given formulas.
- Next, outline how to iterate over each pixel `(x,y)`, compute `C`, initialize `Z = 0 + 0i`, and apply the iteration formula `Z = Z² + C` for 50 steps.
- For each iteration, check if `|Z|² > lim`. If so, mark the point as *not* in the set; otherwise, it is part of the set.
- Pack bits into bytes: For each row, iterate over pixels, write a bit (1=set, 0=not) to an output buffer. After every 8 pixels, emit a byte with MSB first. Pad the last byte if necessary.
- Handle edge cases like `N % 8 != 0` by appending zeros to the last row’s bytes.

**Output format:**
- Header: `"P4\nN N"` (no newline after header).
- Binary pixel data: Packed bits as described, written in binary mode (e.g., `sys.stdout.buffer.write()`).

---

### Key Requirements
- **Language**: Pure Python 3.x.
- **Input**: Command-line argument `N` (must be parsed and validated to be a positive integer).
- **Algorithm**:
  - Exactly 50 iterations per point.
  - Escape threshold: `lim = 2.0 * 2.0`.
  - Use squared magnitude (`zr² + zi²`) for comparison; no square roots.
  - Iteration formula: `Z = Z*Z + C` (complex multiplication).
- **Output**:
  - Header: `"P4\nN N"` (exactly, no extra whitespace or newlines).
  - Pixel data:
    - 1 bit per pixel (MSB first), packed into bytes.
    - Last byte of each row padded with zeros if `N % 8 != 0`.
- **Validation**: Output must match the reference for `N=200` when compared via `cmp`.

### Notes
- **Edge cases**: Handle invalid `N` (e.g., non-integer or negative) by raising a clear error.
- **Bit packing**: Ensure bit order is MSB-first when writing bytes. For example, if the first pixel in a row is in the set, the output byte should have bit 7 set (binary `100...0`).
- **Performance**: The script must run efficiently for `N=200` (or larger) without unnecessary overhead.
- **Output format**: No trailing newline after header or binary data. Use `sys.stdout.buffer.write()` for binary output to avoid encoding issues.
- **Complex math**: Implement complex number arithmetic manually if the LLM does not have built-in support (e.g., using tuples `(zr, zi)`).
