### Prompt Structure
Below is a few-shot prompting structure to generate Mandelbrot set code in C++ adhering to the problem requirements. The examples illustrate the correct structure and style:

**Example 1 (N=8):**
```cpp
#include <stdio.h>

int main(int argc, char **argv) {
    int N = atoi(argv[1]); // Reads command-line argument
    const double lim = 2.0 * 2.0;
    const int max_iter = 50;

    printf("P4\n%d %d\n", N, N); // Header: PBM P4 format

    for (int y = 0; y < N; ++y) {
        for (int x = 0; x < N; ++x) {
            double cr = 2.0 * x / N - 1.5;
            double ci = 2.0 * y / N - 1.0;

            int pixel_byte = 0;
            bool escape = false;

            for (int iter = 0; iter < max_iter; ++iter) {
                double zr = cr, zi = ci;
                for (int k = 0; k < iter; ++k) {
                    double new_r = zr * zr - zi * zi + cr;
                    double new_i = 2.0 * zr * zi + ci;

                    if ((new_r * new_r + new_i * new_i) > lim)
                        escape = true;
                    zr = new_r; zi = new_i;
                }

                if (!escape && (zr * zr + zi * zi <= lim))
                    pixel_byte |= (1 << 0); // Bitwise set for in-set
            }

            printf("%c", (pixel_byte >> (7 - ((y % 8) & 7))) & 1 ? '1' : '0');
        }
    }
}
```

**Example 2 (N=16):**
```cpp
#include <stdio.h>

int main(int argc, char **argv) {
    int N = atoi(argv[1]);
    const double lim = 4.0; // Lim squared (lim = 2*2)
    const int max_iter = 5;

    printf("P4\n%d %d\n", N, N);

    for (int y = 0; y < N; ++y) {
        unsigned char packed_byte = 0;
        for (int x = 0; x < N; ++x) {
            double cr = 2.0 * x / N - 1.5;
            double ci = 2.0 * y / N - 1.0;

            int pixel_byte = 0;
            bool escape = false;
            for (int iter = 0; iter < max_iter; ++iter) {
                double zr = cr, zi = ci;
                for (int k = 0; k < iter; ++k) { // Early escape check
                    double new_r = zr * zr - zi * zi + cr;
                    double new_i = 2.0 * zr * zi + ci;

                    if ((new_r * new_r + new_i * new_i) > lim)
                        escape = true;
                    zr = new_r; zi = new_i;
                }
            }

            pixel_byte |= (escape ? 0 : 1); // Set bit if point is in set
        }

        printf("%c", (pixel_byte >> ((y % 8) & 7)) & 1 ? '1' : '0'); // Bitwise packing
    }
}
```

### Key Requirements
- Must be in **exactly C++98 style** (no headers like `<complex>`, only math.h basics).
- Bitwise output packing: MSB first, padded to `8 per byte`; use `(y % 8)` as bit index.
- Command-line argument `N` parsed with `atoi()` (no input validation beyond this).
- **PBM P4 header**: `"P4\n%d %d\n"` where `%d` is `N × N`.
- Binary pixel data written **byte-by-byte** without newline separators between rows.

| Parameter       | Value                     |

| Max Iterations   | `50`                      |
| Escape Threshold (squared) | `lim = 2.0 * 2.0 = 4.0`    |
| Mapping Coordinates: Real → `-1.5 + 2x/N`, Imaginary → `-1.0 + 2y/N`.

### Notes
- **Avoid floating-point inaccuracies** by using `double` for precision but ensure squaring checks directly (`zr² + zi² ≤ lim`).
- For N=200, the loop unrolling could be optimized with bitwise tricks (e.g., `for(int k = 0; k < iter; k *= 2)`, but avoid non-standard C++ extensions like SIMD or templating.
- The reference validations expect **strict output** (no extra whitespace). Bit manipulation must respect the PBM packing rules (pad with zeros if `<8` bits per row).
- Focus on the core: *Iteration, coordinate mapping, bitwise pixel packing*.
