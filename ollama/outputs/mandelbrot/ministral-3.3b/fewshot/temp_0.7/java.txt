### **Prompt Structure**
Generate a Java program that computes and outputs the Mandelbrot set for an input size `N` using the following specifications:

#### Example Adaptation:
The provided example (`nbody`) demonstrates the structure of command-line argument handling, output to stdout, and iterative loop formatting. Focus on adopting these conventions without duplicating unrelated logic (e.g., body physics calculations).

```
Main method: Takes `N` from CLI.
Output format:
- P4 header: "P4\nN N" (no quotes).
- Pixel data: 8 pixels packed per byte (MSB-first bits), padded with zeros for rows not divisible by 8.
Iteration logic:
For each complex `C = (real(C), imag(C))` in the grid,
- Initialize `Z = 0 + 0i`.
- Repeat 50 times: `Z = Z*Z + C`.
- If `|Z|² > lim`, exit loop and mark pixel as not in set.
- Else, mark pixel as in set.

Coordinate mapping:
real(C) = 2.0 * x / N - 1.5
imag(C) = 2.0 * y / N - 1.0

Algorithm:
Loop over all (x,y) pairs in [0,N-1]×[0,N-1]:
- For each C, compute iterations.
- Pack bits into bytes (MSB first), appending zeros if needed.

Constraints:
- Use exactly `lim = 2.0 * 2.0`.
- No square roots; compare squared magnitude: `zr*zr + zi*zi <= lim`.
```

- **Output**: Raw P4 binary data + header; no newline characters beyond header.
- **Correctness**:
  - Validate with `cmp` for N=200.
  - Strictly follow bit-packing rules (8 pixels/byte, MSB-first).
- **Code Style**:
