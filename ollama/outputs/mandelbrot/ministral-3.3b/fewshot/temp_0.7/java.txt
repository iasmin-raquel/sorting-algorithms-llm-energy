**Your task:**
Implement a Mandelbrot generator in Java adhering strictly to the following parameters:
- Command-line input: `N` (size of grid).
- Output: Binary PBM P4 header + packed pixel bytes via `System.out`.
- No helper methods; embed all logic directly. Write only the minimal required code snippet to reproduce the exact output when validated with N=200.

### Key Requirements
- **Language**: Strictly Java 8+ syntax (no third-party imports; rely on primitive types only).
- **Precision**: Use `double` for complex arithmetic.
- **Output format**:
  - Header: `"P4"` newline followed by N rows (each row’s width is `(N*8/8)` bytes, zero-padded).
  - Pixel data: Packed bits per row (MSB-first), zero-padded per byte.
- **Algorithm**:
  - Grid spans `[-1.5, 0.5]` (real) × `[-1.0, 1.0]` (imaginary).
  - Escape threshold = 4.0; max iterations = 50.
  - Set pixel = `0` if iteration count ≤ 50 (in set); else `255`.
- **No validation libraries**: Assume output matches reference on binary level when run for N=200.

### Notes
- **Edge case handling**: Assume `N` is always integer and ≥ 2.
- **Bit packing**: Each pixel = 8 bits (2 bytes), but write packed rows to stdout as raw bytes (no newline between rows).
- **Precision**: Floating-point errors are acceptable if the output matches reference for N=200; avoid exact bit-level mismatches unless critical.
- **Avoid**: Using `MandelbrotSet` classes or external libraries. Implement purely algorithmically.
- **Output format note**: The PBM header must include no trailing newlines beyond `"P4"` newline. Rows must be zero-padded to byte-length `(N*8/8) = N` bytes per row.
