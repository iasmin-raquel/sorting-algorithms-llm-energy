**Target Task:**
Write a Python script that generates the Mandelbrot set for `N`×`N` pixels using `sys.argv[1]` as input. Output must be PBM P4 format (header + packed binary data).

---

### Key Requirements
- **Must implement**:
  - Command-line argument parsing via `int(sys.argv[1])`.
  - Mandelbrot iteration logic with fixed *max_iter=50* and escape threshold `4.0`.
  - Exact region bounds: `real=[−1.5,0.5]`, `imaginary=[−1.0,1.0]`.
- **Output format**:
  - PBM P4 header (ASCII) followed by packed MSB-first binary pixels.
  - Zero-padding per row for bit-perfect alignment.
- **No auxiliary code**: Only the core function generating the set *and* writing stdout.

### Notes
1. **Packing**: Pixels must be bit-packed per row (MSB first), padded to align.
2. **Avoid helper functions**: The LLM should self-contain the Mandelbrot loop logic.
3. **Edge cases**:
   - No trailing newline after header.
   - Correctly handle `N=200` for validation compliance.
4. **Example hint for packing**:
   ```python
   # Pseudocode: Convert 2D array to packed bits
   packed_bits = sum(row << (i * row_length) for i, row in enumerate(rows))
   ```
5. **Performance note**: Prioritize minimalism over readability; omit non-essential comments unless critical (e.g., “bit-pad” in PBM spec).
