### Prompt Structure
Here’s a concise few-shot prompt template for solving the Mandelbrot set generation problem based on the given requirements:

---
**Example 1 (N-body simulation):**
The provided n-body code structure includes:
- A function `main(n)` that reads integer command-line argument `n` for simulation steps.
- Output is written directly to stdout using `print()` statements (e.g., energy values).
- Key logic: body physics computations looped via external counter (here, N=simulation steps).

---

**Target Problem: Mandelbrot Set Generator**
1. Implement a Python function that takes integer command-line argument `N` and produces the following output:
   - **PBM P4 Header**: `"P4\n${N} ${N}\n"` (written as literal string to stdout).
   - **Pixel Data**: 8-bit packed bits (MSB = set, LSB = not set), padded with zeros if `N % 8 ≠ 0`.
     *Example*: For a row with 9 pixels (`N=23`), first byte encodes [bits 0-7+1], second byte adds zeros.
   - **Iterations**: Exactly 50 per complex point, using the formula:
     `Z = Z*Z + C` (starting at `(0,0)`) with threshold `lim=4.0`.
   - Coordinate mapping: `C.x = 2*x/N – 1.5`, `C.y = 2*y/N – 1.0`.
   - Validation: Output must match the reference PBM for N=200 exactly (byte-per-byte).

---
**Key Requirements**
- Strictly output raw PBM header + binary pixels to stdout **only**.
- No function wrappers (e.g., avoid returning values or files).
- Explicit iteration limit and escape threshold (`lim = 4.0` squared magnitude).
- Packed bits must use `MSB=1` for set, `LSB=0` otherwise.

---
**Variable Values**
```python
N         = int(sys.argv[1])              # Command-line argument (e.g., "200")
max_iterations = 50                       # Fixed per problem specs
lim       = 4.0                          # lim² = 4.0², threshold for escape
```

---
**Notes**
- **Ambiguities**: Model may infer `sys`/`open()` but enforce that raw `print()` is sole output method.
- **Edge Cases**:
  - Padding zeros in non-divisible-by-8 rows (e.g., byte for 9 pixels = `[bits 0..7 + 1, 0]`).
  - Validate packed bits are MSB-first (little-endian convention).
- **Avoid**: Print ASCII art or auxiliary debug logs; only stdout matters.
