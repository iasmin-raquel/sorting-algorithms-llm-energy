#### **Example 1: N=8 (for illustration)**
```cpp
#include <cstdio>
#include <cmath>

int main(int argc, char* argv[]) {
    int N = atoi(argv[1]); // Must be passed as command-line arg

    // --- Mandelbrot core ---
    const double lim = 4.0; // Escape threshold squared (2.0 * 2.0)
    const int max_iter = 50;

    for (int y = 0; y < N; ++y) {
        for (int x = 0; x < N; ++x) {
            double cr = 2.0 * x / N - 1.5;
            double ci = 2.0 * y / N - 1.0;

            int iter = 0;
            double zr = 0, zi = 0;
            while (iter < max_iter && zr*zr + zi*zi <= lim) {
                double new_zr = zr*zr - zi*zi + cr;
                double new_zi = 2 * zr * zi + ci;
                zr = new_zr; zi = new_zi;
                iter++;
            }
            // Pack bits (MSB=in set, LSB=not in set)
            printf("%c", (iter == max_iter) ? '1' : '0');
        }
    }

    return 0;
}
```

**Target Problem:**
Write a C++ program that:
1. Takes `N` as a command-line argument.
2. Generates the Mandelbrot set over `[-1.5, 0.5]` × `[-1.0, 1.0]` in an N×N grid.
3. Outputs PBM P4 header (`"P4\nN N"` followed by newline) **and** binary pixel data (8 bits/pixel, MSB-first).
   - Pad last byte of rows with zeros if `N % 8 != 0`.
4. Use exactly:
   - `max_iter = 50`
   - `lim = 2.0 * 2.0` (escape threshold squared)
   - Coordinate mapping: `cr = 2.0*x/N - 1.5`, `ci = 2.0*y/N - 1.0`.
5. Validate correctness via `cmp output.pbm reference.pbm` for N=200.

---
### **Key Requirements**
- **Strict adherence to PBM P4 format**: Header must be `"P4\nN N"` (no extra whitespace).
- **Bit-packing**: Each pixel is 1 bit (MSB = in set, LSB = not). Write bytes MSB-first.
- **No floating-point inaccuracies**: Use exact arithmetic for `lim` and coordinate mapping.
- **Command-line input**: Parse `N` from `argv[1]` (e.g., `./mandelbrot 200`).
- **Output validation**: Binary data must match reference exactly for N=200.
