### Key Requirements
- **Language**: Pure Java (no external libraries like `java.awt` or `javax.imageio`).
- **Input Handling**:
  - Parse `N` from `args[0]` via `Integer.parseInt(args[0])`.
  - No additional arguments allowed.
- **Algorithm**:
  - Use **50 iterations** per pixel, escape threshold **4.0**.
  - Map `(x,y)` to complex plane: `c = (real + offsetX) + i*(imag + offsetY)`, where:
    - `offsetX = (-1.5 + 0.5/N)*N` (center real axis).
    - `offsetY = (-1.0 + 1.0/N)*N` (center imaginary axis).
- **Output**:
  - Write PBM header manually (e.g., `"P4\n200 200"`).
  - Pack bits MSB-first, zero-pad rows to full byte.
  - No extra whitespace or comments in binary data.
- **Precision**: Use `double` for complex plane arithmetic; avoid floating-point errors.

### Notes
- **Ambiguity Risk**: The prompt avoids specifying exact PBM header text (e.g., `"P4\n200 200"`), trusting the LLM to infer it from the binary output structure. Ensure the generated code writes a valid PBM header *before* pixel data.
- **Edge Cases**:
  - Handle `N=1` correctly (single-pixel grid).
  - Zero-padding per row: For odd bits, pad with zeros to form a full byte.
- **Performance**: The LLM should optimize loops for minimal overhead (e.g., avoid redundant calculations). Benchmarking is implicit via the problem’s constraints.
