#### **Example 1: Naive Iteration (N=8)**
```java
public class Mandelbrot {
    public static void main(String[] args) {
        int N = Integer.parseInt(args[0]);
        double lim = 2.0 * 2.0;
        System.out.println("P4\n" + N + " " + N); // Header

        for (int y = 0; y < N; ++y) {
            for (int x = 0; x < N; ++x) {
                double cReal = 2.0 * x / N - 1.5;
                double cImag = 2.0 * y / N - 1.0;
                int pixelBits = iterate(cReal, cImag, lim);
                System.out.write((pixelBits << 4) & 0xFF); // Packed bits
            }
        }
    }

    private static int iterate(double cr, double ci, double lim) {
        double zr = 0.0, zi = 0.0;
        for (int i = 0; i < 50; ++i) {
            double nr2 = zr * zr + zi * zi;
            if (nr2 > lim) return 0; // Not in set
            double nzr = zr * zr - zi * zi + cr;
            double nzi = 2.0 * zr * zi + ci;
            zr = nzr; zi = nzi;
        }
        return 1; // In set (|Z|² ≤ lim)
    }
}
```

#### **Example 2: Optimized Bit-Packing (N=16)**
```java
public class Mandelbrot {
    public static void main(String[] args) {
        int N = Integer.parseInt(args[0]);
        double lim = 4.0; // lim² = 16
        System.out.println("P4\n" + N + " " + N); // Header

        for (int y = 0; y < N; ++y) {
            int packedBits = 0;
            for (int x = 0; x < N; ++x) {
                double cReal = 2.0 * x / N - 1.5;
                double cImag = 2.0 * y / N - 1.0;
                int pixelBits = iterate(cReal, cImag, lim);
                packedBits = (packedBits << 1) | (pixelBits & 1); // Rotate + append
            }
            System.out.write(packedBits); // Write packed byte
        }
    }

    private static int iterate(double cr, double ci, double lim) {
        double zr = 0.0, zi = 0.0;
        for (int i = 0; i < 50; ++i) {
            double nr2 = zr * zr + zi * zi;
            if (nr2 > lim) return 0;
            double nzr = zr * zr - zi * zi + cr;
            double nzi = 2.0 * zr * zi + ci;
            zr = nzr; zi = nzi;
        }
        return 1;
    }
}
```

**Target Problem:**
Generate a Java program that:
1. Takes `N` (e.g., 200) as a command-line argument.
2. Computes the Mandelbrot set over the range `[-1.5, 0.5]` × `[-1.0, 1.0]` using **exactly 50 iterations** and escape threshold `lim = 4.0` (since `lim = 2.0 * 2.0`).
3. Outputs a PBM P4 bitmap with:
   - Header: `"P4\nN N"`.
   - Pixel data packed as **8 bits per byte, MSB-first** (bit 1 = in set, bit 0 = not in set).
   - Padding zeros for incomplete bytes if `N % 8 != 0`.
4. Validate correctness with `cmp` against a reference for `N=200`.

---
### **Key Requirements**
- **Language**: Pure Java (no external libraries).
- **Input Handling**: Parse `N` from `args[0]`.
- **Precision**: Use `double` arithmetic; avoid floating-point inaccuracies in iteration logic.
- **Output Format**:
  - Strictly follow PBM P4 rules (header + binary data).
  - Pack pixels row-wise, left-to-right, top-to-bottom.
- **Performance**: Optimize for speed (e.g., bit-packing, loop unrolling).
- **Correctness**: Must match reference output for `N=200` after validation.

### **Notes**
- **Bit-Packing**: The examples show two approaches (per-pixel vs. row-wise packing). Prioritize the latter for efficiency.
- **Edge Cases**:
  - Handle `N % 8 != 0` by padding bytes with zeros.
  - Ensure no floating-point overflow in iteration (e.g., clamp `zr/zi` to avoid extreme values).
- **Validation**: The output must pass `cmp` for `N=200`. Avoid hardcoding pixel values—compute dynamically.
- **Ambiguity Risk**: Clarify whether the LLM should generate a single loop (row-wise) or nested loops. Prefer row-wise packing for speed.
