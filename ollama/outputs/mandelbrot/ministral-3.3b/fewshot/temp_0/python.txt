**Few-shot Example for Mandelbrot Set Generation in Python (PBM P4 Output):**

---
**Example 1:**
```python
# Mandelbrot set generator for N=200, 50 iterations, escape threshold 4.0
import sys

def mandelbrot_pbm(N):
    # Initialize PBM header
    print(f"P4\n{N} {N}\n")

    for i in range(N):
        row = []
        for j in range(N):
            # Map (i,j) to complex plane coordinates
            x_real = -1.5 + (2.0 / N) * j
            y_imag =  1.0 - (2.0 / N) * i

            zx, zi = 0.0, 0.0
            iterations = 0
            while abs(zx**2 + zi**2) < 4.0 and iterations < 50:
                zi = 2*zx*zi + y_imag
                zx = zx**2 - zi**2 + x_real
                iterations += 1

            row.append(iterations if iterations == 50 else 0)
        # Pack bits MSB-first, zero-padded per row
        packed_row = int(''.join(str(b) for b in row), 2)
        print(packed_row.to_bytes(1, 'big'))

if __name__ == "__main__":
    mandelbrot_pbm(int(sys.argv[1]))
```

```python
# Simplified version (same logic, different variable names)
import sys

def generate_mandelbrot(N):
    print("P4\n", N, N)  # Header
    for row in range(N):
        packed_row = 0
        for col in range(N):
            x = -1.5 + (2.0 / N) * col
            y =  1.0 - (2.0 / N) * row

            zx, zi = 0.0, 0.0
            count = 0
            while abs(zx**2 + zi**2) < 4.0 and count < 50:
                zi = 2*zx*zi + y
                zx = zx**2 - zi**2 + x
                count += 1

            packed_row |= (count if count == 50 else 0) << (8 * col)
        print(packed_row.to_bytes(1, 'big'))

if __name__ == "__main__":
    generate_mandelbrot(int(sys.argv[1]))
```

- **Algorithm**:

  - Write each packed row as a single byte (`to_bytes(1, 'big')`).
- **Edge Cases**:

- **No External Libraries**: Use only Python’s built-ins (e.g., `math.sqrt`, `int.to_bytes`).
