#### **Example 1: N=8 (for illustration)**
```python
import sys

def mandelbrot_pbm(N):
    lim = 2.0 * 2.0
    max_iter = 50

    # Coordinate mapping for C in [-1.5, 0.5] × [-1.0, 1.0]
    for y in range(N):
        for x in range(N):
            # Map (x,y) → real(C), imag(C)
            c_real = 2.0 * x / N - 1.5
            c_imag = 2.0 * y / N - 1.0

            z_real, z_imag = 0.0, 0.0
            iter_count = 0
            while (z_real*z_real + z_imag*z_imag <= lim) and (iter_count < max_iter):
                new_z_real = z_real * z_real - z_imag * z_imag + c_real
                new_z_imag = 2.0 * z_real * z_imag + c_imag
                z_real, z_imag = new_z_real, new_z_imag
                iter_count += 1

            # Pack bits (MSB=in set, LSB=not in set)
            pixel_byte = (iter_count == max_iter) << 7
            sys.stdout.buffer.write(pixel_byte.to_bytes(1, byteorder='big'))

        # Pad last row to 8 bytes if N % 8 != 0
        padding = (N % 8) * 0xFF
        sys.stdout.buffer.write(padding.to_bytes((N + 7) // 8, byteorder='big'))
    print(f"{N} {N}")

**Target Problem:**
Write a Python script that:
1. Takes `N` as a command-line argument.
2. Generates the Mandelbrot set in PBM P4 format (header + packed bits).
3. Uses **exactly**:
   - `max_iter = 50`
   - `lim = 2.0 * 2.0`
   - Coordinate mapping: `real(C) = 2.0*x/N - 1.5`, `imag(C) = 2.0*y/N - 1.0`.
4. Outputs to stdout **exactly** as specified (header + binary data).
5. Must validate for `N=200` with `cmp`.

---
### **Key Requirements**
- **Strict adherence to PBM P4 format**:
  - Header: `"P4\nN N"` (no quotes, newline after header).
  - Binary pixel data: 8 bits per pixel (MSB = in set), packed MSB-first.
  - Padding: Last row padded with zeros if `N % 8 != 0`.
- **No floating-point inaccuracies**: Use exact arithmetic for `lim` and coordinate mapping.
- **Iteration formula**: `Z = Z*Z + C` (complex multiplication).
- **Input/Output**:
  - Read `N` from `sys.argv[1]`.
  - Write header + binary data to stdout (no file I/O).
- **Performance**: Optimize for speed (avoid redundant calculations).
