### Prompt Structure
Implement a C++ program that calculates and plots the Mandelbrot set on an N-by-N bitmap in PBM P4 format. The program should receive N as a command-line argument and use exactly 50 iterations and escape threshold lim = 2.0 * 2.0. The output must be identical to the reference when validated with `cmp output.pbm reference.pbm` for N=200.

### Key Requirements
- Write code in C++
- Receive N as a command-line argument
- Use exactly 50 iterations and escape threshold lim = 2.0 * 2.0
- Output must be PBM P4 format: header, binary pixel data to stdout
- The output must be identical to the reference when validated with `cmp` for N=200

### Variable Values
- Maximum iterations: 50
- Escape threshold (squared): lim = 2.0 * 2.0
- A point belongs to the set if |Z|² <= lim after all iterations
- Use squared magnitude (zr*zr + zi*zi) to avoid computing square roots
- Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
- Coordinate mapping:
  - real(C) = 2.0 * x / N - 1.5
  - imag(C) = 2.0 * y / N - 1.0

### Notes
The output should be padded with zeros on the right if N is not divisible by 8 for each row. The program must not include any error handling or user interface, focusing solely on the Mandelbrot set calculation and PBM P4 output.
