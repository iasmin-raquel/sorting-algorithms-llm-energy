### Prompt Structure
Write a Python script that generates the Mandelbrot set in PBM P4 format given an N-by-N bitmap size. The script should receive N as a command-line argument and adhere to the specified parameters.

### Key Requirements
- Write the output in PBM P4 format with bits packed MSB first, zero-padded per row
- Use exactly 50 iterations and an escape threshold of 4.0
- The plot region should be real values from [-1.5, 0.5] and imaginary values from [-1.0, 1.0]
- Write the PBM P4 header as text followed by binary pixel data to stdout

### Variable Values
- N: int(sys.argv[1])
- Maximum iterations: 50
- Escape threshold: 4.0
- Plot region real: [-1.5, 0.5]
- Plot region imaginary: [-1.0, 1.0]

### Notes
The output should be identical to the reference when validated with `cmp output.pbm reference.pbm` for N=200. Ensure that the output format conforms to the PBM P4 specification and that there are no deviations from the provided parameters.
