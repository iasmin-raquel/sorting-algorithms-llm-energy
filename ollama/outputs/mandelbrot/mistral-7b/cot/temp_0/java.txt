### Prompt Structure
Write a Java program that takes N as a command-line argument and generates the Mandelbrot set in PBM P4 format. The program should perform 50 iterations with an escape threshold of lim = 2.0 * 2.0, using squared magnitude to avoid computing square roots. The output should be identical to the reference when validated with `cmp` for N=200.

### Key Requirements
- The program must be implemented in Java
- It should receive N as a command-line argument
- Use exactly 50 iterations and escape threshold lim = 2.0 * 2.0
- Write PBM P4 header and binary pixel data to stdout
- Produce output validatable with `cmp` for N=200

### Variable Values
- Maximum iterations: 50
- Escape threshold (squared): lim = 2.0 * 2.0
- A point belongs to the set if |Z|² <= lim after all iterations
- Use squared magnitude (zr*zr + zi*zi) to avoid computing square roots
- Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
- Output format: PBM P4 with pixel packing of 8 per byte, MSB first

### Notes
The program should handle the case where N is not divisible by 8 by padding the last byte of each row with zeros on the right. The output should only contain the header and binary pixel data, without any additional comments or formatting.
