### Prompt Structure
Write a Java program that takes an N (integer) as command-line argument and generates the Mandelbrot set in PBM P4 format. The program should use 50 iterations and an escape threshold of 4.0, plotting the region real in [-1.5, 0.5], imaginary in [-1.0, 1.0]. The output should be written byte-by-byte with MSB first, zero-padded per row.

### Key Requirements
- The program must be implemented in Java
- It should receive N as a command-line argument via Integer.parseInt(args[0])
- Use exactly 50 iterations and escape threshold 4.0
- Write PBM P4 header and binary pixel data to stdout

### Variable Values
- Maximum iterations: 50
- Escape threshold: 4.0
- Plot region real: [-1.5, 0.5]
- Plot region imaginary: [-1.0, 1.0]
- Output format: PBM P4
- Bit packing: MSB first, zero-padded per row

### Notes
Ensure the output is identical to the reference when validated with "cmp output.pbm reference.pbm" for N=200. Be aware that the model may generate code that does not strictly adhere to these constraints but still produces correct results.
