### Prompt Structure
Write a Python script that generates the Mandelbrot set in PBM P4 format for a given N. The script should receive N as a command-line argument and adhere to the specified parameters.

### Key Requirements
- The script must be written in Python
- The script should accept N as an integer command-line argument via `int(sys.argv[1])`
- The script should use exactly 50 iterations and escape threshold 4.0
- The output should be in PBM P4 format, with bits packed MSB first and zero-padded per row

### Variable Values
- Maximum iterations: 50
- Escape threshold: 4.0
- Plot region (real): [-1.5, 0.5]
- Plot region (imaginary): [-1.0, 1.0]
- Output format: PBM P4

### Notes
Ensure that the output is identical to the reference when validated with `cmp output.pbm reference.pbm` for N=200. The script should write both the text header and binary pixel data to stdout.
