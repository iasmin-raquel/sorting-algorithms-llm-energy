### Prompt Structure
Write a Java program that generates an image of the Mandelbrot set using the PBM P4 format. The program should receive N as a command-line argument and produce output validatable with cmp for N=200.

### Key Requirements
1. Implemented in Java
2. Receives N as a command-line argument
3. Uses exactly 50 iterations and escape threshold lim = 2.0 * 2.0
4. Writes PBM P4 header and binary pixel data to stdout
5. Produces output validatable with cmp for N=200

### Variable Values
- Maximum Iterations: 50
- Escape Threshold (squared): lim = 2.0 * 2.0
- A point belongs to the set if |Z|² <= lim after all iterations
- Use squared magnitude (zr*zr + zi*zi) to avoid computing square roots
- Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
- Coordinate mapping:
    real(C) = 2.0 * x / N - 1.5
    imag(C) = 2.0 * y / N - 1.0

### Notes
Ensure the output format follows PBM P4 standards, and any padding is included as necessary when N is not divisible by 8. The example code provided serves as a general structure guide but should be adapted to solve this specific problem.
