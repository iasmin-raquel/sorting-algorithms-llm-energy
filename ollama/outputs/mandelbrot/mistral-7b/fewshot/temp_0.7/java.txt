### Prompt Structure
Write a Java program that plots the Mandelbrot set using the provided parameters and outputs in PBM P4 format. The program should receive N as a command-line argument, use 50 iterations and an escape threshold of 4.0, and write the PBM P4 header and binary pixel data to stdout.

### Key Requirements
1. Implemented in Java
2. Receives N as a command-line argument via Integer.parseInt(args[0])
3. Uses exactly 50 iterations and escape threshold 4.0
4. Writes PBM P4 header and binary pixel data to stdout

### Variable Values
- Maximum iterations: 50
- Escape threshold: 4.0
- Plot region (real): [-1.5, 0.5]
- Plot region (imaginary): [-1.0, 1.0]
- Output: PBM P4 format, bits packed MSB first, zero-padded per row
