### Key Requirements
- The solution must be implemented in Java
- The program should receive N as a command-line argument
- Use exactly 50 iterations and escape threshold `lim = 2.0 * 2.0`
- Write PBM P4 header and binary pixel data to stdout
- Produce output validatable with `cmp` for N=200

### Variable Values
- Maximum iterations: 50
- Escape threshold (squared): `lim = 2.0 * 2.0`
- A point belongs to the set if `|Z|² <= lim` after all iterations
- Use squared magnitude (`zr*zr + zi*zi`) to avoid computing square roots
- Iteration formula: `Z = Z*Z + C`, starting from `Z = (0, 0)`
- Coordinate mapping:
    - real(C) = `2.0 * x / N - 1.5`
    - imag(C) = `2.0 * y / N - 1.0`

### Notes
The provided example code is for the n-body problem and should not be used as a reference for implementing the Mandelbrot set. The structure, argument reading, main loop, and output to stdout are the key elements to extract from the example.
