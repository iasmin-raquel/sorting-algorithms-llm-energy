### Prompt Structure
You are to implement the Mandelbrot set using Python, following the Computer Language Benchmarks Game's specifications. Your code must:
- Accept N as a command-line argument.
- Generate an N-by-N bitmap of the Mandelbrot set with 50 iterations.
- Use squared magnitude (zr*zr + zi*zi) to avoid square roots.
- Map coordinates via real(C) = 2.0 * x / N - 1.5 and imag(C) = 2.0 * y / N - 1.0.
- Output in PBM P4 format (header + binary pixel data, 8 pixels per byte, MSB first).
- Validate against the reference.pbm for N=200 using `cmp output.pbm reference.pbm`.

### Key Requirements
- Use exactly 50 iterations.
- Escape threshold lim = 2.0 * 2.0 (4.0).
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0.
- Output PBM P4 header (P4\n N N) with 8 pixels per byte, MSB first.
- Pad with zeros if N not divisible by 8.
- Write only header and binary data to stdout.

### Variable Values
- N: Command-line argument (e.g., 200).
- Max iterations: 50.
- Escape threshold: 4.0 (lim = 2.0 * 2.0).
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0.

### Notes
- Ensure N=200 for validation; code must handle padding for non-divisible N.
- Use squared magnitude to avoid sqrt computations.
- Correctly implement the iteration formula Z = Z² + C.
- Validate output with `cmp output.pbm reference.pbm` for N=200.
