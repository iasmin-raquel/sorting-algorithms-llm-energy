### Prompt Structure
You will generate a C++ program to compute the Mandelbrot set according to the Computer Language Benchmarks Game's requirements. The program must:
- Accept N as a command-line argument
- Use exactly 50 iterations with escape threshold lim = 4.0
- Map complex numbers using real(C) = 2.0*x/N -1.5 and imag(C) = 2.0*y/N -1.0
- Output PBM P4 format with 8 pixels per byte, MSB first
- Validate output with cmp against reference.pbm for N=200

### Key Requirements
- Use exactly 50 iterations
- Escape threshold lim = 2.0 * 2.0 (4.0)
- Coordinate mapping: real(C) = 2.0*x/N -1.5, imag(C) = 2.0*y/N -1.0
- Output PBM P4 header (P4\n N N) with 8 pixels per byte, MSB first
- Pad with zeros if N not divisible by 8
- Write only header and binary pixel data to stdout

### Variable Values
- N: integer command-line argument
- max_iterations: 50
- lim: 4.0
- pixel_format: 8 per byte, MSB first
- coordinate_mapping: real(C) = 2.0*x/N -1.5, imag(C) = 2.0*y/N -1.0

### Notes
- Ensure N is divisible by 8 for correct padding
- Use squared magnitude (zr*zr + zi*zi) to avoid sqrt
- Validate output with cmp output.pbm reference.pbm for N=200
