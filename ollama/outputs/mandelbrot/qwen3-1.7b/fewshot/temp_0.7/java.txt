### Prompt Structure
You are to generate Java code that implements the Mandelbrot set using the Computer Language Benchmarks Game's specifications. The code must:

- Accept N as a command-line argument
- Use exactly 50 iterations with escape threshold lim = 4.0
- Map coordinates using real(C) = 2.0 * x / N - 1.5 and imag(C) = 2.0 * y / N - 1.0
- Compute Z = Z² + C with Z starting at (0, 0)
- Output PBM P4 header and binary pixel data (8 per byte, MSB first)
- Validate output with cmp against reference.pbm for N=200

### Key Requirements
- Use exactly 50 iterations
- Escape threshold lim = 2.0 * 2.0 = 4.0
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
- Use squared magnitude (zr*zr + zi*zi) to avoid square roots
- Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
- Output PBM P4 header and binary pixel data (8 per byte, MSB first)
- Pad with zeros if N not divisible by 8
- Validate output with cmp for N=200

### Variable Values
- Maximum iterations: 50
- Escape threshold (squared): 4.0
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
- Use squared magnitude (zr*zr + zi*zi)
- Iteration formula: Z = Z*Z + C, starting from Z = (0, 0)
- Output format: P4 header, 8 per byte, MSB first

### Notes
- The code must handle N=200 exactly, ensuring the output matches the reference.pbm
- The iteration check must use squared magnitude to avoid square roots
- The coordinate mapping must be applied correctly for all pixels
- The output must be written in portable bitmap format with proper padding
