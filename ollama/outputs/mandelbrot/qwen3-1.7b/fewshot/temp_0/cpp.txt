### Prompt Structure
You are to implement the Mandelbrot set in C++ according to the Computer Language Benchmarks Game. The code must:
- Accept N as a command-line argument
- Use exactly 50 iterations and escape threshold lim = 2.0 * 2.0
- Output PBM P4 header and binary pixel data (8 per byte, MSB first)
- Validate output with `cmp output.pbm reference.pbm` for N=200

### Key Requirements
- N must be provided as a command-line argument
- Use exactly 50 iterations
- Escape threshold is 2.0 * 2.0
- Use squared magnitude (zr*zr + zi*zi) to avoid sqrt
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
- Output PBM P4 header ("P4\nN N\n") with 8 bytes per row, padding with zeros if needed
- Ensure output matches reference for N=200

### Variable Values
- N: integer from command line argument
- max_iterations: 50
- lim: 2.0 * 2.0
- coordinate_mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0

### Notes
- Must correctly handle coordinate mapping and iteration formula
- Ensure escape condition (|Z|² <= lim) is checked accurately
- Handle padding for non-divisible by 8 rows
- Output must match reference for N=200
