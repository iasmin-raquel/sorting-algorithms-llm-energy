### Prompt Structure
You are to implement the Mandelbrot set in Java, following the specified parameters and output format. The code must:
- Take N as a command-line argument
- Use exactly 50 iterations with escape threshold lim = 2.0 * 2.0
- Compute squared magnitude (zr*zr + zi*zi) to avoid square roots
- Map coordinates using real(C) = 2.0 * x / N - 1.5 and imag(C) = 2.0 * y / N - 1.0
- Output PBM P4 format with 8 pixels per byte, MSB first (bit 1 = in set, bit 0 = not in set)
- Validate against reference.pbm for N=200

### Key Requirements
- Use exactly 50 iterations
- Escape threshold lim = 2.0 * 2.0
- Coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0
- Output PBM P4 header and binary pixel data
- Pad with zeros if N not divisible by 8
- Write only header and pixel data to stdout

### Variable Values
- N: integer command-line argument
- iterations: 50
- lim: 2.0 * 2.0
- coordinate mapping: real(C) = 2.0 * x / N - 1.5, imag(C) = 2.0 * y / N - 1.0

### Notes
- Ensure the code uses squared magnitude (zr*zr + zi*zi) for accuracy
- Handle N not divisible by 8 by padding with zeros
- Validate output with cmp output.pbm reference.pbm for N=200
