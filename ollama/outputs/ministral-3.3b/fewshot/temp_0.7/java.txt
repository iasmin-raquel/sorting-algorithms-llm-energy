**Task: Implement a N-body simulation for Jovian planets under mutual gravitational attraction. Use the same constants and initial conditions provided, with these specifications:**
1. **Input Handling:** Accept `N` (number of time steps) from command-line arguments.
2. **Symplectic Integrator:** Follow this sequence:
   - Update all velocities first,
   - Then update all positions based on accumulated gravitational forces.
3. **Momentum Adjustment:** Offset the Sun’s initial velocity to ensure zero total system momentum.
4. **Output Formatting:** Print initial and final energy percentages with %.9f precision.
5. **Precision:** Ensure numerical stability using at least 8 significant digits (error tolerance: ≤1e-8).

---

### Key Requirements
- **Language:** Strictly Java.
- **Command-line Argument:** `N` must be parsed as an integer, passed to the simulator.
- **Symplectic Integration Order:** Velocity updates first, position updates second.
- **Zero Total Momentum:** Dynamically correct Sun’s velocity for exact momentum conservation.
- **Energy Output:** Print initial and final gravitational potential energy (normalized as %) using `%9f`.
- **Precision Handling:** Avoid floating-point errors exceeding 1e-8 via careful arithmetic or iterative checks.
- **No External Dependencies:** Only standard Java libraries (`java.lang`, `math`, I/O) are allowed.
