### Prompt Structure
You are tasked with generating a Python implementation of the n-body problem for simulating the orbits of Jovian planets (Sun, Jupiter, Saturn, Uranus, Neptune) under mutual gravitational forces. The code must:

1. Accept `N` as a command-line argument.
2. Use a symplectic integrator with two phases: first update all velocities based on current positions and masses, then update all positions based on updated velocities and masses.
3. Adjust the Sun’s initial velocity to ensure zero total momentum in the system (offsetMomentum).
4. Compute and print the **initial** and **final** energy of the system (kinetic + potential) with a precision of 9 decimal places (`%.9f`).
5. Use the provided physical constants exactly as given:
   - `PI = 3.141592653589793`
   - `SOLAR_MASS = 4 * PI * PI`
   - `DAYS_PER_YEAR = 365.24`

```python

    N = int(sys.argv[1])
    # Define constants and initial conditions (see below)
    # Implement symplectic integrator with offsetMomentum adjustment
    # Compute energy at start and end of simulation

```

**Key constraints:**
- Use **exact** values from the provided constants and initial conditions.
- Do not hardcode any physics beyond gravitational forces (use `G = 1` implicitly via mass scaling).
- Avoid explicit parallelization unless necessary for performance; focus on correctness first.

### Key Requirements
- **Language:** Python only.
- **Input:** Command-line argument `N` (number of time steps).
- **Output:** Two lines: initial and final energy, formatted as `%.9f`.
- **Integrator:** Symplectic Euler (velocity-first then position-update).
- **Momentum offset:** Adjust Sun’s velocity to zero total momentum.
- **Precision:** Validate with `ndiff -abserr 1.0e-8` for `N=1000`.
- **No external libraries** beyond Python standard library (`math`, `sys`).

### Notes
1. **Ambiguity in `offsetMomentum`:** The prompt assumes the Sun’s velocity is adjusted to cancel total momentum, but does not specify how (e.g., scaling by mass or vectorially). Clarify if the LLM must implement this explicitly.
2. **Energy Calculation:** Include both kinetic (`0.5 * sum(mass_i * v^2)`) and potential (`-G * sum(mass_i / r_ij)`) terms, where `r_ij` is pairwise distance between bodies.
3. **Time Step:** Assume a fixed timestep (e.g., `dt = 1.0`) unless specified otherwise; the LLM should derive it from initial conditions if needed.
4. **Symplectic Integrator:** Emphasize that velocities must update *before* positions, and use explicit formulas for gravitational acceleration (`a_i = G * sum(m_j / r_ij^2) * (r_ij - r_i)`).
