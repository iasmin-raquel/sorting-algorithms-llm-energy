### Prompt Structure
Implement a C++ program to simulate the n-body problem with N=1000 bodies, where N is provided as a command-line argument. The simulation should accurately calculate the energy of the system after a specified number of time steps using a symplectic integrator. The output should be formatted to display the final energy to 9 decimal places.

The simulation involves the gravitational interaction between the Sun and eight planets: Jupiter, Saturn, Uranus, and Neptune.  The code must precisely use the provided constants and initial conditions for each body. Specifically, the Sun's initial velocity needs to be adjusted so that the total momentum of the system is zero before starting the integration. This adjustment should be done by offsetting the Sun’s initial velocity. The integrator should update all velocities first, followed by updating all positions.

The code must include the provided C++ code snippet as a template for efficient calculations and parallelization.  This includes the `Index`, `EvalPart`, `EvalATimesU`, `EvalAtTimesU`, `GetThreadCount`, and `spectral_game` functions. The `spectral_game` function should be used to perform the simulation.

The program should take a single command-line argument, N, representing the number of bodies in the simulation. If no argument is provided, it defaults to 2000.  The final energy of the system (calculated as the sum of kinetic energies) should be printed to standard output with 9 decimal places using the format `%.9f`.

### Key Requirements
*   **Language:** The code must be written in C++.
*   **Command-Line Argument:** The program must accept an integer N as a command-line argument, representing the number of bodies.
*   **Output Format:** The final energy should be printed to standard output with 9 decimal places using `%.9f`.
*   **Symplectic Integration:** Implement a symplectic integrator that updates all velocities before updating positions.
*   **Momentum Conservation:** Adjust the Sun's initial velocity to ensure zero total momentum at the start of the simulation.
*   **Code Inclusion:** The provided C++ code snippet must be included verbatim in the program.
*   **Validation:** The output should be validated with `ndiff -abserr 1.0e-8` against a reference solution (N=1000).
