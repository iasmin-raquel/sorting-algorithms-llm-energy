### Prompt Structure

Act as a senior software engineer tasked with designing a Java implementation for simulating the n-body problem specifically for Jovian planets under mutual gravitational influence. The goal is to produce code that adheres strictly to the Computer Language Benchmarks Game (CLB) criteria, ensuring numerical accuracy validated by `ndiff -abserr 1.0e-8` with N=1000 iterations.

Begin by breaking down the problem into clear, logical steps:

1. **Define Constants and Physical Parameters**:
   - Include all provided constants (`PI`, `SOLAR_MASS`, `DAYS_PER_YEAR`) exactly as given.
   - Ensure these are used consistently throughout the code to avoid precision errors.

2. **Initial Conditions Setup**:
   - Parse and store initial positions (x, y, z) and velocities (vx, vy, vz) for each planet (Sun, Jupiter, Saturn, Uranus, Neptune).
   - Include mass values for each body.
   - Implement a method to adjust the Sun’s velocity (`offsetMomentum`) so that the total momentum of the system remains zero.

3. **Symplectic Integrator Implementation**:
   - Use a symplectic integrator (specifically: update velocities first, then positions).
   - Break down the integration into two phases:
     - Phase 1: Update all velocities based on pairwise gravitational forces.
     - Phase 2: Update all positions using the new velocity values.

4. **Energy Calculation**:
   - Compute and print the initial and final total energy of the system (kinetic + potential) with precision to 9 decimal places (`%.9f`).
   - Ensure energy conservation is validated within the required tolerance.

5. **Command-Line Argument Handling**:
   - The program must accept `N` as a command-line argument, representing the number of integration steps.
   - Validate that `N` is a positive integer before proceeding.

6. **Precision and Validation**:
   - Use double precision floating-point arithmetic to ensure accuracy.
   - Ensure all calculations respect the provided constants and initial conditions exactly.

7. **Output Format**:
   - Print the initial energy followed by the final energy, each formatted as `%.9f`.

8. **Code Structure**:
   - Organize code into logical methods (e.g., `calculateGravitationalForce`, `updateVelocities`, `updatePositions`).
   - Use helper classes or structs to represent celestial bodies and their properties.

---

### Key Requirements
- **Language**: Explicitly target Java.
- **Input Handling**: Accept `N` as a command-line argument (e.g., `java <ClassName> 1000`).
- **Momentum Conservation**: Adjust the Sun’s velocity to ensure total system momentum is zero.
- **Symplectic Integrator Order**:
  - Update velocities first, then positions.
- **Energy Validation**: Output initial and final energy with precision to 9 decimal places (`%.9f`).
- **Precision**: Use `double` for all floating-point calculations; avoid rounding errors.
- **No External Dependencies**: Implement all logic within the provided constants and initial conditions.
