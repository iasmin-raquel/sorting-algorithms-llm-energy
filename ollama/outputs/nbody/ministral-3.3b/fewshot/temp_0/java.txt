**Your Task:**
Implement a Java program that simulates the orbits of Jovian planets (Sun, Jupiter, Saturn, Uranus, Neptune) under mutual gravitational forces. The code must:
1. Accept `N` as a command-line argument.
2. Use a symplectic integrator with order: update velocities first, then positions.
3. Adjust the Sun’s initial velocity to ensure total system momentum is zero (`offsetMomentum`).
4. Print the initial and final energy of the system in %.9f format.

**Key Features:**
- Use gravitational forces between all bodies (including the Sun).
- Apply a time step of `1e-6` days.
- Output must be validated with `ndiff -abserr 1.0e-8` for N=1000 iterations.

---

### Key Requirements
- **Language:** Java only.
- **Command-line Argument:** Must parse `N` (number of iterations).
- **Symplectic Integrator Order:**
  - Update all velocities first (`Δv = F * Δt`).
  - Update all positions second (`Δr = v * Δt`).
- **Momentum Conservation:** Adjust Sun’s velocity to zero net momentum.
- **Energy Output:** Print initial and final energy in %.9f format (e.g., `0.123456789%`, `0.123456788%**).
- **Precision:** Use double-precision arithmetic; avoid floating-point errors beyond 1e-8.
- **Gravitational Force:** Compute pairwise forces using Newton’s law of gravitation (`F = G * m1 * m2 / r²`).
- **Time Step:** Fixed at `1e-6` days (no adaptive stepping).

### Notes
1. **Symplectic Integrator:** The integrator must follow the order: velocities updated first, then positions. This ensures long-term stability.
2. **Momentum Adjustment:** The Sun’s velocity will be adjusted post-initialization to zero net momentum (e.g., via `offsetMomentum()`).
3. **Energy Calculation:** Total energy includes kinetic (`0.5 * Σ m_i v_i²`) and potential (`Σ -G * m_i m_j / r_ij`).
4. **Precision:** Use `double` for all calculations; avoid rounding errors in intermediate steps.
5. **Ambiguity Risk:** The prompt assumes the LLM will handle array indexing (e.g., `pos[i]` for 3D vectors) and nested loops for pairwise forces. Clarify if the target model requires explicit loop constructs or vectorized operations.
6. **Output Format:** Ensure energy is printed as a percentage of total mass-energy (e.g., `KE + PE` normalized to `SOLAR_MASS`).
