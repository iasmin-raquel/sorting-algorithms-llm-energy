### Prompt Structure
Write a C++ program that calculates the first N digits of Pi using the Unbounded Spigot Algorithm (Gibbons). The program should perform the following steps:

1. Initialize variables q, r, t, and k according to the given initial state.
2. Implement the next_step function as described in the algorithm requirements.
3. Implement extract(x) and produce(d) functions as defined above.
4. Advance the algorithm by one term using next_step until q > r is false.
5. Compute d = extract(3) and e = extract(4).
6. If d == e, output digit d and call produce(d). Otherwise, advance the algorithm again.
7. Output digits in groups of 10, with each line ending with a tab, colon, and running total: "\t:N". If the last line has fewer than 10 digits, pad with spaces on the right.
8. Receive N as a command-line argument.

### Key Requirements
- The program must be implemented in C++ using the GMP library for arbitrary precision arithmetic.
- The program should receive N as a command-line argument.
- The program must use the initial state, next_step, extract, and produce operations exactly as defined above.
- The program should perform both extract(3) and extract(4) for digit verification.
- The output format should be identical to the one specified in the problem description.

### Variable Values
- q: 1 (initial state)
- r: 0 (initial state)
- t: 1 (initial state)
- k: 0 (initial state)

### Notes
- The program may need to handle integer overflow and underflow during calculations.
- The program should validate the input N to ensure it is a positive integer.
- The program should use appropriate data structures from the GMP library for handling large integers.
