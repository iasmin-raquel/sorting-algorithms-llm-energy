**Prompt for Implementing the pidigits Problem in Java**

Implement the **pidigits** problem from the Computer Language Benchmarks Game using the **Unbounded Spigot Algorithm (Gibbons)**. The goal is to calculate the first N digits of π with arbitrary precision arithmetic, outputting 10 digits per line and the running total. The output must match the reference file `output.txt` when validated against `reference.txt` for N=30.

---

### Key Requirements:
1. **Algorithm Implementation**:
   - Use **BigInteger** for arbitrary precision arithmetic.
   - Follow the steps:
     - `next_step`: Increment `k`, update `r`, `t`, and `q`.
     - `extract(x)`: Compute `floor((q*x + r)/t)`.
     - `produce(d)`: Compute digits by checking `d = extract(3)` and `d = extract(4)`.
     - Loop until `q > r` is false.
   - Stateful variables: `q`, `r`, `t`, `k`.

2. **Output Format**:
   - 10 digits per line.
   - Each line ends with `\t:N` (e.g., `\t:30` for N=30).
   - Pad with spaces if the line has fewer than 10 digits.

3. **Command-Line Argument**:
   - Accept N as a command-line argument (e.g., `java pidigits 30`).

4. **Code Structure**:
   - Use `BigInteger` for all arithmetic operations.
   - Implement the algorithm in a stateful loop.
   - Ensure the output matches the reference file.
