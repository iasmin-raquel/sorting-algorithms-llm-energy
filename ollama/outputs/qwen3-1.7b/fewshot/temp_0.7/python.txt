### **Step 4: Simulate Orbits Using a Symplectic Integrator**

To simulate the orbits, we use the **Verlet method**, a symplectic 
integrator that preserves energy over time.

#### **Implementing the Verlet Method**
```python
def verlet_integration(state, dt, n_steps):
    """
    Perform Verlet integration on a state vector.
    state: (x, y, vx, vy) (in units consistent with the system)
    dt: time step
    n_steps: number of steps
    """
    x, y, vx, vy = state
    state = [x, y, vx, vy]
    for _ in range(n_steps):
        # Update position
        x += vx * dt
        y += vy * dt
        # Update velocity
        vx = (x - 2 * y) * dt / dt
        vy = (y - 2 * x) * dt / dt
        state = [x, y, vx, vy]
    return state
```
